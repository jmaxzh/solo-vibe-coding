# Desktop UI Design Principles

## Usage

- Read the [shared principles](../SKILL.md#shared-principles) and select the following rules for the target OS, input method, and window usage.
- For interfaces running in a browser, also read [web principles](web.md).

## Platform principles

- **Window adaptation**: support target window sizes and display scaling. Adjust panels and content to available space while retaining access to primary content and actions.
- **Working-interface density**: for task-oriented interfaces at desktop widths, consider text size, row height, and padding together when adjusting density. [Source context](sources.md#working-interface-density).
