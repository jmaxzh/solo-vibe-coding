# Desktop UI Design Principles

First read the [shared principles](../SKILL.md#shared-principles). This table uses the entry document’s rule format: the required result is the criterion. Each Basis names an L1 principle in that document.


## Usage

| ID | When | Required result (criterion) | Basis |
| --- | --- | --- | --- |
| DT1 | selecting desktop rules | must select for the target OS, input method, and window usage. | P2 |
| DT2 | the interface runs in a browser | must also read [web principles](web.md). | P2 |

## Platform principles

| ID | When | Required result (criterion) | Basis |
| --- | --- | --- | --- |
| DT3 | adapting desktop windows | must support target window sizes and display scaling. | P2 |
| DT4 | available window space changes | must adjust panels and content while retaining access to primary content and actions. | P3 |
| DT5 | adjusting density on task-oriented interfaces at desktop widths | must consider text size, row height, and padding together. [Source context](sources.md#working-interface-density). | P2 |
