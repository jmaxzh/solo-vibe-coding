# Mobile UI Design Principles

## Usage

- Read the [shared principles](../SKILL.md#shared-principles) and select the following rules for the target device, OS, and grip.
- For mobile web, also read [web principles](web.md).

## Platform principles

- **Touch and reachability**: position frequent actions within reach for the target device size and grip. Separate actions with serious consequences from frequent actions when proximity could cause accidental activation.
- **Usable area**: avoid system bars, cutouts, and system gesture regions.
- **Native component visuals**: for native iOS or Android interfaces, prefer the target platform's recognizable component visuals. Express brand choices through the platform's supported theming and customization mechanisms. [Source context](sources.md#native-component-visuals).
- **Native typography**: for native iOS or Android interfaces, map text to the platform's text styles or roles and respect the user's system font-size setting. [Source context](sources.md#native-typography).
