# Mobile UI Design Principles

## Usage

- Read the [shared principles](../SKILL.md#shared-principles) and select the following rules for the target device, OS, and grip.
- For mobile web, also read [web principles](web.md).

## Platform principles

- **Touch and reachability**: position frequent actions within reach for the target device size and grip. Separate actions with serious consequences from frequent actions when proximity could cause accidental activation.
- **Usable area**: avoid system bars, cutouts, and system gesture regions.
- **Native component visuals**: for native iOS or Android interfaces, prefer the target platform's recognizable component visuals. Express brand choices through the platform's supported theming and customization mechanisms. Adapted from [Impeccable, iOS component conventions](https://github.com/pbakaus/impeccable/blob/9fadc41729c38fd47d7ae622b501558653f9d2e9/.agents/skills/impeccable/reference/ios.md#L5-L9) and [Android component conventions](https://github.com/pbakaus/impeccable/blob/9fadc41729c38fd47d7ae622b501558653f9d2e9/.agents/skills/impeccable/reference/android.md#L5-L9).
- **Native typography**: for native iOS or Android interfaces, map text to the platform's text styles or roles and respect the user's system font-size setting. Adapted from [Impeccable, iOS text styles](https://github.com/pbakaus/impeccable/blob/9fadc41729c38fd47d7ae622b501558653f9d2e9/.agents/skills/impeccable/reference/ios.md#L22-L26) and [Android text roles and scaling](https://github.com/pbakaus/impeccable/blob/9fadc41729c38fd47d7ae622b501558653f9d2e9/.agents/skills/impeccable/reference/android.md#L22-L26).
