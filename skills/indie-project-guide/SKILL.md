# Indie Project Guide

为产品方向已经确定的独立开发者，按当前任务选择专业指导和素材参考，帮助其做好设计、营销与内容表达。

## 按当前任务工作

- 根据用户当前要求提供建议、评审或实现，各任务可以独立进入。
- 沿用已有产品事实、品牌、审美选择、技术栈和实现；从当前上下文判断产品阶段，只补充影响本次任务的缺失信息。
- 选择最贴合任务的主导 Skill，必要时搭配解决独立问题的辅助能力。用途重叠时，由当前模型结合输入、交付形式和项目条件判断。
- 设计判断结合具体用途和参考；专业指导中的风格偏好服从用户与项目已有选择。
- 外部 Skill 按上游地址远程读取，无须安装。读取方式、相对引用和执行依赖见 [远程读取与发现](references/skill-loading.md)。

## 应用指导

将选中指导用于用户要求的产物，并说明影响结果的关键选择。参考定位到具体页面、截图、组件源码或素材文件，动态效果提供可播放示例。内容依据真实产品与证据；交付状态以实际取得的文件、运行和验证结果为准。
