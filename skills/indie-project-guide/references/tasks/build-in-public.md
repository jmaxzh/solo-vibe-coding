# Build in public

用于公开开发、开发日志、设计取舍、社交内容、发布素材与小工具传播。

根据真实进展选择内容：原型、视觉实验、实现难点、阶段成果或已有使用证据。结合传播目标判断技术读者与产品受众的关系，保留开发者自己的语气。

## 选择

| 当前任务 | 候选 |
| --- | --- |
| 单条帖、线程、社交表达、个人语气、素材复用 | social |
| 主题方向、内容组合、可检索与可分享内容 | content-strategy |
| 用户要求发布计划或某次产品/功能发布 | launch |
| 评估某个免费小工具是否适合作为传播入口 | free-tools |
| 开源或开发者工具的长期公开实践、边界和节奏 | samber 的 build-in-public |

## 素材如何配合

同一个真实原型可按当前请求衍生出页面演示、交互录屏、封面、信息图或短视频。文字看 [文案](positioning-copy.md)，静态素材看 [图片](images.md)，视频看 [视频指南](video.md)。

参考包可包含一个主要视觉参考、局部截图、图标家族与具体动效源码。按任务说明参考对象的构图、排版或节奏；已有品牌和个人语气持续沿用。
