# 研究与分析

用于用户提出的研究、页面转化、追踪分析和营销定时任务。依据本次可获得的访谈、页面、公开资料、流量和事件数据选择能力；证据不足时说明可判断的范围。

| 当前任务 | 候选 | 输入与用途 |
| --- | --- | --- |
| 访谈、反馈归纳或公开需求信号 | customer-research | 使用真实资料，区分原话、主题和待验证假设 |
| 分析具体页面的转化问题 | cro | 页面内容与流程可用于定性评审；效果判断需要相应数据 |
| 设计埋点、事件、归因或检查数据质量 | analytics | 根据现有技术栈和测量问题确定追踪方案 |
| 设计定时或事件触发的营销工作 | marketing-loops | 在用户选择的任务中定义状态、去重、执行和停止条件 |
