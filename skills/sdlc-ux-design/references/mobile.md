# Mobile UX Design Principles

## Usage

- Read the [shared principles](../SKILL.md#shared-principles) and select the following rules for the target device, OS, and grip.
- For mobile web, also read [web principles](web.md).

## Platform principles

- **Keyboard and task access**: when the keyboard opens, keep the active field, errors, and necessary controls visible or reachable by scrolling.
- **Navigation and back behavior**: follow target-system conventions. Distinguish going up a level, closing temporary UI, and switching primary areas. Preserve filters, scroll position, and other browsing state as needed when returning. In mobile interfaces, adapt navigation to the available space and target platform. Keep core tasks reachable and their logical relationships recognizable. [Source context](sources.md#navigation-and-back-behavior).
