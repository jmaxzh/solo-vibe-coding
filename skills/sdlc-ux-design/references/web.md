# Web UX Design Principles

## Usage

- Read the [shared principles](../SKILL.md#shared-principles) and select the following rules for browser usage.
- For mobile browsers, also read [mobile principles](mobile.md). For desktop-window behavior or frequent keyboard/mouse usage, also read [desktop principles](desktop.md).

## Platform principles

- **History and tabs**: make navigation match expectations for browser back and forward. Preserve native behavior such as opening links in new tabs. Avoid duplicate or meaningless history entries.
- **Link and button semantics**: use native links for navigation and native buttons for actions. Do not simulate controls with elements that lack the required interaction semantics and behavior.
- **Local status announcements**: in web interfaces, communicate local count or status changes that users need to know with enough context for assistive technology users to understand them. Preserve the user's current focus during these announcements.
