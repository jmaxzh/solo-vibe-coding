# Desktop UX Design Principles

## Usage

- Read the [shared principles](../SKILL.md#shared-principles) and select the following rules for the target OS, input method, and window usage.
- For interfaces running in a browser, also read [web principles](web.md).

## Platform principles

- **Shortcuts and focus restoration**: provide common shortcuts according to platform conventions without disrupting text input. After closing an overlay, restore focus to the trigger or the control needed for the next action.
- **WPF action consistency**: in WPF interfaces, apply the same execution conditions and target resolution to all entry points for the same action in the same context. Derived from [UI UX Pro Max, WPF commands, parameters, and input bindings](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/713eef51b04efc98d6fa565323b495f7c9c89fd4/src/ui-ux-pro-max/data/stacks/wpf.csv#L28-L32).
