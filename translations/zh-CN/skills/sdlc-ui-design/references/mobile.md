# 移动端 UI 设计原则

先读取[公共原则](../SKILL.zh-CN.md#公共原则)。本表沿用入口文档的规则格式；要求结果同时作为检查标准。每行的 Basis 指向入口文档的 L1 原则。


## 使用方式

| ID | 触发条件 | 要求结果（检查标准） | Basis |
| --- | --- | --- | --- |
| MB1 | 选择移动规则时 | 必须按目标设备、操作系统和握持方式选取。 | P2 |
| MB2 | 面向移动网页时 | 必须同时读取[网页原则](web.md)。 | P2 |

## 平台原则

| ID | 触发条件 | 要求结果（检查标准） | Basis |
| --- | --- | --- | --- |
| MB3 | 安排高频操作时 | 必须使其在目标设备尺寸和握持方式下便于触达。 | P3 |
| MB4 | 相邻布局可能导致误触时 | 必须将后果严重的操作与高频操作分开。 | P3 |
| MB5 | 放置移动界面内容和控件时 | 必须避让系统栏、屏幕缺口和系统手势区域。 | P3 |
| MB6 | 设计原生 iOS 或 Android 控件视觉时 | 必须优先采用目标平台容易识别的控件视觉语言。[来源上下文](sources.md#原生控件视觉)。 | P2 |
| MB7 | 在原生控件中表达品牌选择时 | 必须使用平台支持的主题及定制机制。 | P2 |
| MB8 | 设置原生 iOS 或 Android 文字时 | 必须映射到平台的文本样式或角色。[来源上下文](sources.md#原生排版)。 | P2 |
| MB9 | 呈现原生 iOS 或 Android 文字时 | 必须响应用户的系统字号设置。 | P3 |
