# 移动端 UI 设计原则

## 使用方式

- 读取[公共原则](../SKILL.zh-CN.md#公共原则)，按目标设备、操作系统和握持方式选取以下原则。
- 移动网页同时读取[网页原则](web.md)。

## 平台原则

- **触控与触达**：根据目标设备尺寸和握持方式，将高频操作放在便于触达的位置。相邻布局可能导致误触时，将后果严重的操作与高频操作分开。
- **可用区域**：避让系统栏、屏幕缺口和系统手势区域。
- **原生控件视觉**：对原生 iOS 或 Android 界面，优先采用目标平台用户容易识别的控件视觉语言。通过平台支持的主题及定制机制表达品牌选择。[来源上下文](sources.md#原生控件视觉)。
- **原生排版**：对原生 iOS 或 Android 界面，按平台的文本样式或角色组织文字，并响应用户的系统字号设置。[来源上下文](sources.md#原生排版)。
