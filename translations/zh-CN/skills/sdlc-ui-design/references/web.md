# 网页 UI 设计原则

先读取[公共原则](../SKILL.zh-CN.md#公共原则)。本表沿用入口文档的规则格式；要求结果同时作为检查标准。每行的 Basis 指向入口文档的 L1 原则。


## 使用方式

| ID | 触发条件 | 要求结果（检查标准） | Basis |
| --- | --- | --- | --- |
| WB1 | 选择网页规则时 | 必须按浏览器使用场景选取。 | P2 |
| WB2 | 面向移动浏览器时 | 必须同时读取[移动端原则](mobile.md)。 | P2 |
| WB3 | 涉及桌面窗口行为或高频键鼠操作时 | 必须同时读取[桌面端原则](desktop.md)。 | P2 |

## 平台原则

| ID | 触发条件 | 要求结果（检查标准） | Basis |
| --- | --- | --- | --- |
| WB4 | 布局网页内容时 | 必须按可用视口和内容重排。 | P2 |
| WB5 | 文字缩放或方向变化时 | 必须在布局中支持该变化。 | P3 |
| WB6 | 内容需要横向滚动时 | 必须避免整页横向滚动，将二维布局所需的横向滚动限制在该内容区域。 | P3 |
| WB7 | 网页内容异步加载或更新时 | 必须在布局中考虑，避免阅读位置和操作目标意外移动。[来源上下文](sources.md#异步布局稳定性)。 | P3 |
