# 桌面端 UI 设计原则

## 使用方式

- 读取[公共原则](../SKILL.zh-CN.md#公共原则)，按目标操作系统、输入方式和窗口使用场景选取以下原则。
- 界面在浏览器中运行时，同时读取[网页原则](web.md)。

## 平台原则

- **窗口适配**：支持目标窗口尺寸和显示缩放。根据可用空间调整面板和内容，保持主要内容与操作可达。
- **工作型界面密度**：对桌面宽度的工作型界面，调整密度时应同时考虑字号、行高和内边距。[来源上下文](sources.md#工作型界面密度)。
