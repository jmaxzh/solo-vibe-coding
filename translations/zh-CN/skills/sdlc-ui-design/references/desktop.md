# 桌面端 UI 设计原则

先读取[公共原则](../SKILL.zh-CN.md#公共原则)。本表沿用入口文档的规则格式；要求结果同时作为检查标准。每行的 Basis 指向入口文档的 L1 原则。


## 使用方式

| ID | 触发条件 | 要求结果（检查标准） | Basis |
| --- | --- | --- | --- |
| DT1 | 选择桌面规则时 | 必须按目标操作系统、输入方式和窗口使用场景选取。 | P2 |
| DT2 | 界面在浏览器中运行时 | 必须同时读取[网页原则](web.md)。 | P2 |

## 平台原则

| ID | 触发条件 | 要求结果（检查标准） | Basis |
| --- | --- | --- | --- |
| DT3 | 适配桌面窗口时 | 必须支持目标窗口尺寸和显示缩放。 | P2 |
| DT4 | 窗口可用空间变化时 | 必须调整面板和内容，同时保持主要内容与操作可达。 | P3 |
| DT5 | 调整桌面宽度的工作型界面密度时 | 必须同时考虑字号、行高和内边距。[来源上下文](sources.md#工作型界面密度)。 | P2 |
