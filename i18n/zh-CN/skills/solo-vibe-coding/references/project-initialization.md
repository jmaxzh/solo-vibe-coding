# 项目初始化

用于新建或接手工程项目，准备可重复运行的本地环境与适用的自动检查。先读取项目指令、README、依赖与锁文件、配置示例、启动脚本、已有质量标准和流水线，沿用有效成果，按实际缺口准备工程基础。

1. **确认必要的工程选择。** 沿用已确认需求与项目选型；缺少会影响工程准备的技术选择时，按[架构与技术设计](architecture.md)评估，未约定时使用其中的默认技术栈。关键需求或范围缺口按[需求澄清](requirements.md)补足。
2. **准备本地环境。** 按[本地环境与调试准备](development.md#本地环境与调试准备)准备运行时、依赖、环境变量和实际需要的配套服务，执行适用的迁移与开发数据初始化，验证服务连接和一条关键应用路径。沿用原生或容器化流程，保留已有本地数据，区分首次初始化与可重复启动。
3. **落实质量基线。** 按[质量指标与自动检查](quality-and-ci.md)确定适合项目规模的标准，复用或补齐检查工具、本地入口及适用的自动执行，验证检查有效性。质量基线建立后再推进功能实现和结构性重构。

按[项目知识库规范](project-knowledge.md)在已有文档中维护必要的环境搭建、启动、停止和检查方法，按内容需要建立文档。报告实际准备、启动和验证结果，以及缺少的前置条件。现成基座、Gin 示例和 Compose 组合见[开发参考](resources/development.md)；后续按[技术方案流程](technical-planning.md)及[开发与质量](development.md)开展工程任务，继续沿用本次建立的环境与标准。
