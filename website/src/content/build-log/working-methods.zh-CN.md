Solo Vibe Coding 为你正在用的编程助手加入一套专业工作要求：按任务连接相关指导与现成资源，优先考虑适合现有项目的做法，为工程任务建立适当检查，并把有用的约定保存在项目中，供后续修改沿用。

你可以从想做的东西或想改的行为开始，减少先自行拼接一组专业 Skill 的工作。Agent 按当前任务选择相关指导，各类任务可以独立进入。

## 看一次真实任务

[收藏导出案例](/solo-vibe-coding/zh-CN/case-study/bookmark-export/)展示同一个小项目的两次修改：先增加 CSV 导出，再新开会话，改为只导出当前筛选的收藏。案例说明同一 Agent 有无 Skill 的实际结果、检查、额外工作和比较范围。

一个能用的工具，本身不能证明 Skill 的贡献。能力强的 Agent 也可能已经处理得很好，读取更多指导也有成本。这个案例不承诺普遍的速度或质量优势。

## 在自己的项目里试一试

案例提供可下载的起始项目和两轮需求。在编程助手中打开它，[加入 Solo Vibe Coding](/solo-vibe-coding/zh-CN/getting-started/)，完成第一次修改；再新开会话，提出第二次修改。

也可以换成你自己的目标。说明希望改变什么、哪些已有用法需要保留，试用成果，并确认重要选择。Skill 提供指导；助手、可用工具和项目条件仍然决定实际能交付什么。
