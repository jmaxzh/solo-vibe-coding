Solo Vibe Coding 已经形成一个初始版本。接下来，需要一个地方，让独立开发者理解它、尝试它，并看到后续进展。

这个官网是我们的第一次公开构建。它介绍项目，也记录背后的选择。它不代表这个 Skill 已经取得了有数据验证的提效、质量或用户增长成果。

## 从一件具体的事开始

这个 Skill 面向已有明确产品方向的开发者，为当前任务选择专业指导，覆盖获客与转化、视觉与交互、需求与沟通、架构与技术设计、开发与质量、生产部署与发布。

每类任务都可以独立进入。工程工作优先确定质量指标和自动检查，过程中产生的可复用知识则留在项目里。

因此，官网从任务示例出发。开发者应该能够找到自己正在解决的问题，复制调用方式，并在安装前理解预期交付。

## 首版保持具体、可用

首版包含产品首页、快速开始、六类任务示例和构建日志。英文与中文使用独立网址，并提供含义对应的内容。

网站使用 Astro 生成静态 HTML，通过已有公开仓库的 GitHub Pages 发布。先使用 GitHub 默认地址，减少购买与配置自定义域名的步骤。GitHub Actions 负责检查，并且只发布生成后的官网文件。

视觉采用暖白、石墨黑与橙色，以深色任务工作台呈现调用示例。可复制的提示词、易读的正文和手机导航，是优先做好的交互。

## 让每项选择有处可查

项目知识与代码一起维护。知识库入口指向官网需求、架构、决策记录和验证说明。公开日志讲述构建过程，维护文档则描述当前系统和操作方法。

实际实现与验证情况，可以在仓库中查看：

- [官网源码](https://github.com/jmaxzh/solo-vibe-coding/tree/main/website)
- [项目知识库](https://github.com/jmaxzh/solo-vibe-coding/blob/main/docs/README.md)
- [架构与设计决策](https://github.com/jmaxzh/solo-vibe-coding/blob/main/docs/decisions.md)
- [构建与部署执行记录](https://github.com/jmaxzh/solo-vibe-coding/actions)

## 用能观察到的结果继续改进

发布前，检查构建、链接、语言对应、元数据、键盘操作、手机布局和能够自动检测的无障碍问题。发布完成则需要部署成功、公开页面能够访问的实际证据。

搜索收录、排名、AI 引用与实际安装量，需要在上线后另外收集依据。这些是后续观察的结果，首版不能预先承诺。

如果你尝试了这个 Skill，可以[通过 Issue 记录任务和实际结果](https://github.com/jmaxzh/solo-vibe-coding/issues)。一个具体成果或遇到的困难，都能成为下一次改进的依据。
