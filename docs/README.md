## 维护方式

需求描述稳定行为，架构描述当前实现，ADR 记录具有持续影响的选择与取舍。普通参数与实现细节以代码、配置、测试为准；决策索引指向其位置。

修改行为、操作方法、依赖条件或部署方式时，同时更新对应主维护文档和受影响的双语内容。重要决策被替换时新增 ADR 并关联旧记录，保留可追溯依据。

调研、历史评分、执行结果和评审过程独立存放。操作文档可独立使用，无须先阅读这些档案。官网发布内容由 `website/src/` 维护，研究档案不进入网站构建。
