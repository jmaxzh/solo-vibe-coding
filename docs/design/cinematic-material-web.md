# 电影感材质官网设计规范

适用于希望以深色空间、鲜明材质和大尺度构图建立辨识度的产品官网与落地页。目标是让主视觉、文字与背景共同形成一个有前后层次的场景，同时让访客读懂产品并找到下一步。

密集操作界面和长篇阅读页面应按任务另行设计；同一品牌可以共享字体、色彩角色与控件语言，无须共享大幅主视觉。这是一种可选择的风格，不是所有网站的默认样式。

## 保持的体验与可以变化的表达

| 保持的体验 | 画面中的具体表现 | 可以变化的表达 |
| --- | --- | --- |
| 空间感 | 近处、远处和留白有关系；遮挡、暗部与高光共同建立纵深 | 视角、形态、主体位置、背景环境 |
| 材质感 | 轮廓、厚度、受光与所选材质相符；重要细节在网页实际尺寸仍可辨认 | 金属、玻璃或其他合适材质，反射与折射方式 |
| 构图张力 | 主体尺度、裁切和文字位置形成明确焦点；画面有疏密与明暗变化 | 左右、居中或非对称排版，完整或局部展示主体 |
| 阅读层级 | 标题传达定位，说明补充价值，主按钮指向明确行动 | 字体、字号、换行、按钮形态 |
| 整页连续性 | 首屏之后仍有相容的字阶、间距、光色和组件；每段有自己的信息职责 | 章节布局、背景明暗、图文比例与节奏 |

先在静态画面中建立这些关系，再用动效补充。颜色、三维形态或动画数量都不能单独证明达到目标。

## 首屏构图与素材

把首屏当作一个完整场景安排，而不是分别填满标题区和图片区。主要形态可以越过版心或被视口裁切，但要保留可辨认的关键轮廓。大片暗部用于衬托亮部和组织阅读，局部光色用于引导视线，避免背景、材质和按钮同时争夺注意力。

文字需要稳定的阅读区域。允许主体延伸到文字后方，用构图留白、局部暗部或渐变保持对比；正常内容流中的图片与文字则应保留清楚的间距。图片、渐变、蒙版和视差一起检查，确保边缘自然衔接，运动到极端位置时也不压住文字或入口。

桌面可先用 1440×1000 试排，让定位、价值说明、主入口与主体关键轮廓共同出现。手机可先用 390×844 试排，按阅读顺序重新组织图文；空间不足时允许继续滚动，不通过缩小正文或固定高度强行塞入一屏。再检查中间宽度、断点两侧、长文案与各语言。

素材选择同时考虑形态、光位、文字留白与背景融合。金属应呈现相符的反射，玻璃应呈现相符的厚度和折射；不要求所有材质都有透明、色散或强烈高光。用实际网页尺寸判断质感，不能只看素材原图。

素材简报至少写清：用于哪个场景、主要形态、材质与光位、主体位置和文字安全区、背景衔接、目标尺寸与许可。可使用已有合规素材、原创预渲染、摄影或代码绘制，按收益选择工具。标题、说明和按钮使用网页文字，便于响应式排版、翻译和访问。

## 产品叙事与整页节奏

先复用已有产品事实，确认服务谁、解决什么任务、增加什么价值、主要行动和可公开证据。画面可以抽象，产品说明和操作路径要具体。装饰概念图明确其用途，能力与任务请求基于已确认事实，不能借装饰暗示不存在的功能或实测效果。

本项目首页按以下内容顺序组织：

1. 定位与价值：说明产品用途、受众与开始入口。
2. 六类能力：按当前任务进入指南。
3. 使用与交付：说明准备、开始、推进和检查结果的方法。
4. 安装：提供完整命令、环境要求和详细指南。
5. FAQ 与页脚：说明费用、许可、适用边界与后续入口。

延续首屏的色彩角色与材质暗示，不必每一段都放三维图。可以用大幅场景、编号叙事、步骤与任务卡片形成疏密变化；布局由内容关系决定。按钮、边框、圆角、字阶与间距应能归入少量明确规则，避免章节各自发展一套样式。

中英文分别按自然表达成稿，允许长度、换行和布局不同，事实、功能与操作边界保持对应。不得添加无依据的用户数量、客户标识、评价、效果数字或成功承诺。

## 视觉参数与实现起点

以下是玻璃折射配色的起点，改变材质或品牌时可以重选。颜色承担的职责比色值本身更重要；有透明度、图片或混合模式时，需要检查合成后的实际画面。

| 角色 | 示例值 | 用途 |
| --- | --- | --- |
| 页面底色 | `#070b0d` | 衬托受光主体并连接章节 |
| 主要文字 | `#eff5f1` | 标题与重要信息 |
| 次要文字 | `#b5c2bc` | 说明正文，仍需清楚可读 |
| 主要行动底色 | `#c5f8b9` | 标识优先操作，限制大面积重复 |
| 主要行动文字 | `#101b13` | 与按钮底色形成清楚对比 |

可从约 1320px 的宽屏版心、约 560px 的简介行宽开始试排；手机侧边距可从 20–24px 开始。标题根据语言和字体单独设定流式字号，中文保留适当行距；正文可从 15–16px、约 1.7–2 倍行高开始。间距使用少量递进档位，如 8、16、24、32、48、64、96px。这些是排版起点，应按真实内容调整，不作为审美或可读性合格的公式。

优先复用现有字体、组件与依赖。先把样式限定在本次页面；修改共享导航、布局或变量时检查内页及全部交互状态。沿用项目框架、路由和发布体系，新增依赖应说明可见收益和维护成本。第三方代码、字体及素材核对适用许可，并保留必要归属。

参考实现：[首屏布局](../../website/src/components/Hero.astro)、[装饰场景](../../website/src/components/OrbitScene.astro)、[首页章节](../../website/src/components/Home.astro)、[首页与内页样式边界](../../website/src/layouts/Layout.astro)。具体实现参数以代码为准；本项目的内容、交互与语言要求见[官网需求](../specs/website.md)。

## 动效与运行成本

每类动效都应有清楚用途，例如轻微视差补充纵深、短过渡说明状态变化。主要内容默认可见，不能等动画结束才能阅读或操作；保持浏览器自然滚动，触屏操作不依赖悬停。

尊重系统减少动态效果偏好。持续装饰动画提供可键盘操作的暂停方式，暂停时保留静态画面；离屏或文档隐藏时停止无用绘制。遵循 [WCAG 暂停 停止 隐藏要求](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)，核对自动开始、持续超过五秒且与其他内容并列呈现的运动。关闭 JavaScript 时，正文与核心开始路径仍可用；需要脚本的功能保留清楚的静态状态和说明。

优先用静态图配合必要的轻量变化表达质感，实时三维按明确收益选用。为图片预留尺寸，按显示尺寸选格式与分辨率；记录新增图片、脚本与持续绘制成本，遵守项目预算。当前参考场景在 Canvas 动画循环中以 30fps 为绘制上限、像素比最多 1.5；这是本实现的取舍，不能代替实体设备的流畅度、耗电和加载验证。

## 制作步骤与验收

先完成静态首屏，核对焦点、空间、材质与阅读关系；再延展整页和手机，最后加入有明确用途的动效。每一步是制作中的自检，不额外设置逐步审批；预览、提交、合并和发布遵循当前任务的授权范围。

选择一个已认可、适用于本项目的画面作为比较基准。在相同视口、语言和动效状态下，对照首屏与完整页面，分别判断以下四项，不把它们合成一个总分：

| 验收维度 | 应查看的证据 |
| --- | --- |
| 审美 | 主体是否有可辨的材质与纵深；尺度、留白、明暗是否形成焦点；整页是否连贯，有无局部精致而其余章节粗糙的落差。提供同视口截图作判断依据 |
| 产品理解 | 页面是否交代用途、具体增量和下一步；证据性质是否清楚。目标用户能否复述并完成首次使用，需要真实试用验证 |
| 操作 | 在真实浏览器中试用主入口、任务选择、语言切换、刷新、复制等已有能力；检查键盘焦点、触控命中、暂停和无脚本状态 |
| 工程 | 运行项目规定的构建、链接、资源、响应式与交互检查，检查共享样式回归和运行成本；按项目要求进行独立只读审查 |

普通信息文字与实际背景的对比至少 4.5:1，满足大号文字定义时至少 3:1，依据 [WCAG 文字对比要求](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。图片背景需核对叠加蒙版后的局部背景，包含注记、占位文字及运动极端位置；不能用一对 CSS 色值代替实际检查。抽样检查不等于完整无障碍验收。

主要独立触控按钮以至少 44×44 CSS px 为设计目标，这是本风格的操作约定。检查无横向溢出、正文缩放后仍可阅读、焦点清楚、主要入口不被装饰覆盖。仅断言元素存在或可见，不能证明它能点击或文字可读。

交付可操作预览、桌面与手机的首屏和整页截图、与基准的同视口对照，并分别报告四项结论及尚未验证的部分。工程通过不能替代审美判断或用户效果证据。

> 为【产品与目标受众】制作【页面范围】，主要行动是【具体操作】。采用电影感材质官网风格，以【已认可画面】为比较基准，保留空间、材质、构图焦点和整页连续性，用【材质、形态、光色等可变项】形成这次表达。页面需解释【产品价值、实际用法、开始路径】，只使用【已确认事实与证据】。保留【架构、路由、功能、语言与工程约束】，检查桌面、手机及中间断点的实际阅读和操作。交付【预览、截图、检查范围】，提交与发布范围为【本次授权】。分别评价审美、产品理解、操作和工程，按实际画面对照改进。
