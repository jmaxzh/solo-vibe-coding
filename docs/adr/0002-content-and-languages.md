# ADR 0002：任务导向的双语内容

- 状态：部分替代。受众、首页入口与公开日志内容以 [ADR 0005](0005-user-outcomes-and-audiences.md) 为准；双语与独立网址安排继续有效。
- 日期：2026-11-13
- 对应决策：D01–D04、D22

## 结论

以已有产品方向的独立开发者为受众，先交付首页、快速开始、六类任务指南和构建日志。默认英文，中文使用独立网址并保持内容对应。

## 背景与取舍

README 已有技能定位、安装和能力说明，官网需要帮助新访客理解实际使用场景，并进入一次具体任务。六类任务在现有 Skill 中可独立调用，不建立强制线性工作流。

共用结构与双语数据减少页面漂移；Markdown 用于有实际日期与作者的构建日志。使用独立语言网址而非运行时替换文案，便于直接分享、静态阅读与搜索索引；代价是每次内容变更都需要核对两种语言。

首版任务指南集中在一个完整页面，避免把少量说明拆成缺少独立价值的页面。后续只有形成足够内容时，才独立扩展主题。

## 内容依据

Skill 与仓库 README 是能力、安装、依赖和许可事实的主要来源。任务面板展示调用示例及预期交付，实际案例需要执行证据。首篇日志记录官网工作的真实范围与选择，不宣称尚未验证的增长、效率或引用效果。

当前操作规范与完整决策维护在知识库；公开日志按读者需要表达构建过程。二者用途不同，运行说明不依赖历史过程档案。
