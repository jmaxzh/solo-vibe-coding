# ADR 0003：工作台视觉与渐进增强

- 状态：已采用
- 日期：2026-11-13
- 对应决策：D05–D07、D14

## 结论

采用暖白、石墨黑与橙色，以深色任务工作台呈现实际调用格式；导航和正文静态可用，脚本增强任务选择和复制。

## 背景与取舍

用户确认了工作台与技术出版物结合的方向。大字号标题用于解释价值，任务面板用于解释用法，阅读栏用于指南与文章，浅绿色安装区集中承接首次使用。通过不同内容布局形成层级，而不是重复同一种展示单元。

英文 Manrope 与代码 IBM Plex Mono 自托管，中文使用系统字体。只引入需要的字形文件，避免第三方字体请求；需分发对应 OFL 许可证并维护资源体积。图形使用 SVG，分享卡片另生成 PNG，以保留可编辑性与分享平台兼容性。

标签页减少首页信息密度，但容易让禁用脚本的访问者失去内容。因此初始 HTML 保留六个面板和锚点，脚本启用后才设置标签角色、选择状态、方向键与面板显隐。复制失败时选中原文，保留手动操作路径。

## 无障碍与后果

采用语义结构、跳到正文、清晰焦点、读屏反馈、原生 FAQ 和减少动态效果支持。深浅色面分别检查文字对比度，橙色按钮使用深色文字。桌面与手机分别验证，不以自动化检查代表全部无障碍合规。

视觉参数在 CSS 中维护；行为与状态在组件和浏览器测试中维护。更改这些实现时同步核对本决策目的与相关验收。
