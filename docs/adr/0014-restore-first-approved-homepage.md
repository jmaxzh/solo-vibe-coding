# ADR 0014 恢复首次认可的官网

- 状态：采用，按用户明确要求回退并发布
- 日期：2026-11-16
- 对应决策：D48
- 恢复来源：`f2b27f3c3202bf3a8df6096dfca8e0145893189f`

## 决定

恢复用户首次认可的金属深空光环版。`website/` 整个目录与来源提交一致，包括首页、文案、组件、素材、内页样式、配置与当时的测试。恢复以新提交记录，不重写共享历史；保留现有GitHub Actions与Pages托管，以及工作区无关修改。

## 验证

核对官网目录与来源提交逐文件一致，运行validate和对应浏览器测试，检查中英文实际画面及任务、复制、下载路径。独立只读审查后提交发布，再核对CI/Pages源码SHA与公开地址。过程与结果见[回退记录](../research/website/2026-11-16-restore-first-approved/verification.md)。
