# ADR 0009：沉浸光环首页

- 状态：已实现，沿用现有GitHub Pages发布流程
- 日期：2026-11-14
- 对应决策：D43
- 关联：替代 [ADR 0008](0008-dark-developer-homepage.md) 的视觉构图，延续产品关系、数据、原生任务选项与证据边界

## 结论

首页采用原创金属光环、大字定位、冷蓝粒子轨道和暖橙行动按钮构成沉浸首屏。实际助手使用示意放在随后独立章节，四痛点、步骤、真实内容、安装与 FAQ 以不同构图承接，保留原始内容与核心路径。

## 依据与边界

用户明确要求显著增强视觉表现。Lusion、Active Theory 的沉浸式视觉作为方向参考，不复制其代码或素材。主图使用内置图像生成工具制作并作为WebP自托管；动效使用原生Canvas、CSS与指针事件，不迁移Astro、托管、路由或部署系统，不引入前端框架或3D运行依赖。

主图是装饰概念，不是产品功能、模型能力或真实任务结果。示意、社区场景、界面参考、实际执行记录和功能示例保持各自说明。

## 操作与成本

全部正文和核心操作默认可用。动画偏好控制场景、视差和字带；Canvas离屏、页面隐藏、暂停和减少动画时停止，静态资源提供无脚本视觉。文字区使用独立暗幕，导航与暂停入口按同一高度约定重排，避免复杂图层和响应式布局遮挡文字或操作。

沉浸首屏和叙事行增加页面长度、资源及动效维护成本。视觉表现与可核验的工程行为分别评价；没有真实用户测试时，不将更丰富的视觉、工程通过或静态截图当作理解、转化和总体Pareto改善的证明。
