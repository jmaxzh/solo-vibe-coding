# ADR 0012 黑钛熔光首页

- 状态：采用为本次实现；用户已授权发布，审美效果待用户检查
- 日期：2026-11-15
- 对应决策：D46，替代 D45 的视觉表达

## 选择

以[电影感材质官网设计规范](../design/cinematic-material-web.md)组织新一版首页。全幅黑钛曲面与铜色内光建立尺度和纵深，暖黑背景、白色与琥珀色文字保护阅读，橙色标识主要行动。横向四任务选择、编号痛点、步骤、宽幅执行记录与功能示例、安装和 FAQ 延续相容的字阶与细节。

复用 Astro 组件、双语数据与已有交互；内页继续保留现有视觉，发布仍由原 GitHub Actions 完成。装饰图使用内置 imagegen 生成并以 WebP 自托管，制作原图不参与构建或运行；不新增依赖、字体或服务。沿用受控 Canvas 与轻微平面视差，支持暂停、减少动态效果、离屏和隐藏时停止绘制。

## 检查与取舍

桌面背景型构图分别核对实际文字背景和入口命中，手机按正常内容流排图。复用原有用户行为断言，并对照内页的内容、链接与计算样式。大幅图像和持续动效仍有加载与绘制成本，字节量与帧率上限不能证明实体设备功耗。

同视口首屏与整页对照、检查和独立审查见[本轮记录](../research/website/2026-11-15-ember-titanium/verification.md)。该版本用于让用户检查规范的复用效果；发布授权不等于审美认可，也不等于已完成目标用户研究。
