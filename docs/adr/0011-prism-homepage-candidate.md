# ADR 0011：玻璃折射首页

- 状态：视觉由 [ADR 0012](0012-ember-titanium-homepage.md) 替代；本版曾由用户于2026-11-15授权正式发布
- 日期：2026-11-15
- 对应决策：D45
- 工程基线：ba342fd
- 视觉比较对象：用户已认可的金属光环版f2b27f3

## 方案

桌面以全幅玻璃折射形态建立空间，保留清晰的白色标题、局部暗部与青绿行动。手机及中间宽度以正常内容流排布图文。侧栏助手使用示意、四痛点叙事行、步骤、真实记录与功能示例、安装和FAQ维持既有内容与操作边界。

主图使用内置imagegen生成并以自托管WebP分发，结合原生Canvas和受控平面视差。它是装饰概念，不是实时3D模型或Skill执行证据。构建和运行不依赖制作档案；不增加框架、字体、后端或部署系统。

## 检查与边界

暂停、系统减少动态效果、离屏与隐藏状态控制持续绘制，绘制帧率上限30fps、DPR上限1.5。桌面背景型构图检查实际文字背景对比与入口命中；流式构图检查图文分离。所有主要内容预渲染，不依赖动画结束或JavaScript才能开始。

以同视口画面对照评估焦点、空间、材质、尺度与整页节奏，独立审查与工程检查分别记录。正式发布获得用户授权；没有用户理解、转化、全面辅助设备或实体设备功耗研究，不宣称总体Pareto改善。

## 交付

在website/prism-nocturne隔离制作、验证与独立审查，经PR #9进入main，再由原Website工作流检查和发布。保留原工作区已有Skill修改，不改部署配置。
