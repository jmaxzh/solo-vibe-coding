# ADR 0010：钴蓝编辑式首页

- 状态：实现，使用既有GitHub Pages发布流程

## 结论

首页使用奶油白、钴蓝大字、原创纸面折叠雕塑和橙色强调，形成海报式首屏。蓝底助手示意以顶部任务栏、需求、专业方法和交付检查目标展开。双栏痛点、编号步骤、实测记录、纸张报价示例、橙色安装与蓝色页尾构成连续的编辑版式。

## 实现与边界

沿用Astro组件、CSS和原生Canvas。主图通过内置imagegen制作，以自托管WebP分发，不是交互3D模型，也不作为产品成果或效果证据。构建和运行不依赖制作档案。原任务数据、路由、复制下载和发布配置保持既有方式，不新增框架、后端或字体。

全部主要信息预渲染。动画遵循用户暂停和系统减少动态效果，Canvas在离屏/隐藏时停止，绘制帧率上限30fps、DPR上限1.5；无脚本时保留主图和原生任务路径。主图与正文分区，保持文字对比和装饰留距；手机按内容重排，不劫持滚动。

## 评价与成本

本轮验证的是以新的材质、排版和章节关系形成另一种完整设计。维护范围限定首页；内页保留暖纸阅读与操作系统，后续按用途逐页延展。页面长度、资源和持续绘制开销根据最终产物记录；布局和工程检查不能替代用户审美、理解、转化或实体设备性能研究。
