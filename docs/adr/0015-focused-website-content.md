# ADR 0015：官网聚焦能力、交付方法与安装使用

- 状态：已接受
- 日期：2026-11-23

## 背景与决定

用户要求完整移除使用方式示意、四个社区痛点、实际记录、功能示例及继续探索，包括独立页面、复用内容和资源。官网聚焦六类能力、工程交付方法、安装与通用任务指南。

删除执行记录、报价工具和两篇相关更新文章，并移除空的更新索引。公开范围为中英文首页、开始使用、任务指南及共用 404。导航和元数据仅指向有效内容。

指南与上手页使用独立的通用任务请求，保留六类能力与原任务 ID 的用途；请求不再依赖社区叙事或工具案例。专属图片、下载包、组件、样式、计算逻辑及十进制依赖一并删除。

## 取舍与后果

完整删除减少内容、依赖和维护负担，符合当前公开范围。旧页面和资源返回 404，原有外部链接不再提供对应内容；不以重定向保留已要求移除的材料。首页视觉、双语、安装和任务连续性继续沿用既有实现。

历史决策与研究仅作为仓库维护档案，不进入网站构建、运行和导航。与本决定冲突的早期页面保留、示意和案例发布决定不再适用；当前规范见[官网需求](../specs/website.md)，验证见[测试说明](../testing.md)。
