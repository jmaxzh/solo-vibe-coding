# ADR 0008：深色开发者官网构图

- 状态：首页视觉由 [ADR 0009](0009-immersive-orbit-homepage.md) 替代；产品事实、行为与局部样式边界继续有效

- 对应决策：D42
- 关联：替代 [ADR 0007](0007-homepage-assistant-preview.md) 的首页视觉；保留其任务关系、证据边界和局部样式范围

## 结论

首页采用深色开发者产品官网的分栏构图。桌面左侧介绍定位与开始方式，右侧完整展示四类任务的助手使用示意；手机转为单栏。区段标题、痛点网格、使用步骤、真实内容与安装区共同使用石墨黑、浅色文字和青绿强调，阅读与操作内页维持现有视觉。

## 依据与边界

用户在查看已发布版本后要求更换模板。新的构图参考 [RicoFast](https://ricofast.pages.dev/) 的分栏开发者官网；以当前 Astro 组件与 CSS 独立实现，没有导入模板工程、源码、字体、图标或图片。产品事实、双语内容、原生任务选项、脚本、路由与部署配置保留。

## 收益与成本

定位、具体用法和安装在桌面同一首屏内呈现。任务选择集中为横向任务条，痛点采用连体网格，安装区形成明显的行动层级。减少区段空白与重复框架，控制长页滚动量；保留正文、任务方法、来源与真实证据。

深色背景和更密集的排版需要单独验证文字、触控和焦点。首页与内页继续存在明暗差异；后续若延展到内页，应按用途逐类适配，保持命令、输入校验、下载与阅读行宽。

## 验收

检查双语桌面/手机、所有原有任务行为、键盘与读屏命名、减少动画和无脚本路径。工程检查与独立审查可以验证实现与边界，不能替代用户的审美判断、理解和实际使用测试。
