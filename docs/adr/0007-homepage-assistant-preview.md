# ADR 0007：首页使用示意与局部视觉系统

- 状态：已采纳；使用现有 GitHub Pages 流程发布
- 日期：2026-11-14
- 对应决策：D39–D41
- 关联：更新 [ADR 0003](0003-visual-and-interaction.md) 的首页视觉；延续 [ADR 0006](0006-skill-increment-and-case-evidence.md) 的定位和证据边界

## 结论

首页以浅蓝渐变、居中标题和宽幅助手使用示意介绍产品，依次呈现四个痛点、三步使用、真实内容、安装与 FAQ。默认展示改进产品界面的任务，沿用四类共享任务数据与既有上手流程。首页样式局部生效，阅读与操作内页保留原有视觉。

## 依据与边界

用户明确选择 [NovaOS](https://novaos.framer.website/) 的构图、渐变和页面节奏作为视觉参考。页面以现有 Astro 组件、HTML 和 CSS 独立实现，沿用自托管字体与现有素材，不复用参考站代码或新增运行依赖。

使用示意展示用户需求、助手按任务使用专业方法、希望交付与检查的目标，明确标注示意性质。Skill 安装在现有编程助手中；官网不提供 Agent 执行平台。社区场景、第三方界面参考、实际执行记录和可操作功能示例分别标注，沿用原始来源与证据限制。

## 收益与成本

四个痛点常驻可读，使用示意与安装入口保持任务连续，真实记录和报价工具可从正文直接进入。完整结构增加页面长度与双语文案维护量；视觉协调、理解成本及实际使用收益需要分别验收，不能由构建或浏览器测试推导。

首页色彩、导航与页脚覆盖限定在 `body.homepage`，避免改变内页的阅读密度和交互状态。后续延展到内页时，按页面类型逐步迁移组件与变量，保留可复制命令、校验、下载、锚点和可访问性，并再次比较双语桌面与手机布局。

## 验证

执行 `validate`、现有及补充的浏览器测试，检查任务选择、刷新、语言切换、上手、复制、下载、无 JavaScript、键盘、减少动态效果和文字对比度。另比较内页内容、链接与计算样式；前后截图与审查记录存放维护档案，不成为网站构建或运行依赖。
