# 0013：以精密装配建立官网品牌视觉

状态：由 [ADR 0014](0014-restore-first-approved-homepage.md) 回退。

官网采用象牙白、炭黑与朱橙的精密装配视觉。原创金属框雕塑承担品牌印象，独立的助手示意与真实内容承担使用说明，保留既有双语、内页与主要操作路径。

## 依据与取舍

产品为已有编程助手补充按任务选用的专业方法。多层金属结构将“不同方法共同支撑制作”转化为可见的轮廓、厚度、倒角和层间空间；向上展开的方向回应“从想做到做成”。实际试排还比较了展开书页和暗色光廊：前者的材质与尺度张力较弱，后者与内容站的日常阅读距离较远，因此选择精密装配深化。

主视觉为原创 AI 生成图像，明确标为概念视觉，不冒充产品界面、执行产物或效果证据。静态透明 WebP 提供桌面与手机尺寸，不增加字体、JavaScript 或 3D 依赖。新增图像需要版本化维护，发布包体积增加，仍遵守既有预算。

共享标识、色彩和控件延续到安装指南、案例、工具和更新页面。保留任务选择到安装需求的连续性、公开问题来源、真实执行记录与报价功能；工程检查与产品实际效果分别验证。实现参数以代码和当前需求为准。
