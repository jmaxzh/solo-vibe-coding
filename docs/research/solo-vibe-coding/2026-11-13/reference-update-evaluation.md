# 现成参考接入变更评估

本轮已完成中英文技能的现成参考目录接入，并通过静态完整性校验与新上下文独立只读评审。改进在于六类任务均可直接查找现成来源，同时保留专业指导与制作能力；结论不包含外部服务、素材下载或工程运行效果的验收。

## 变更范围与收益

| 维度 | 修改前 | 修改后与依据 |
| --- | --- | --- |
| 现成参考入口 | 34 个视觉入口位于视觉专业指南中 | 每种语言各有六份独立资源页、54 个唯一入口；新增 3 个视觉来源和 17 个其他场景来源 |
| 任务路由 | 主要进入专业指导，素材发现集中在视觉领域 | SKILL.md 为六类任务同时列出专业指导与现成参考；只找站点可以直接进入资源页 |
| 视觉迁移 | 34 个资源及 89 条使用、获取说明 | 来源顺序与说明完整保留，GSAP 的相对回指随目录层级修正；新增 Recent 发布视频链接 |
| 专业能力 | 128 个上游 Skill 指导条目 | 全部保留，增加约定的四项可选检索指导；生成、制作与评审仍使用原有专业指南 |

| 内容维护 | 视觉素材与方法同文件 | 来源条目各维护一处，其他文档引用对应入口；研究快照不进入运行时依赖 |

## 能力 约束与成本检查

- 默认技术栈及架构专业内容保留；架构页仅增加资源入口。部署目标之后的原文保持一致，包括 Cloudflare 前端与单台 VPS 业务后端的边界。
- quality-and-ci.md、project-knowledge.md、agents/openai.yaml 与许可证保持原样；自托管 Runner、质量基线、项目知识约定和界面元数据未变。
- 新增检索指导按任务读取，实际执行仍依赖可用工具与账号；没有安装或注册外部 Skill、连接账号、执行制作、部署、提交或推送。
- 资源页保留必要访问与使用条件：例如 Mobbin MCP、21st 账号及源码额度、平台模板复制权限、Grafana 指标依赖，以及 Awesome Compose 的本地开发边界。
- 主入口含新增目录链接，存在有界阅读与维护开销：英文字符数为 6672 → 6946，中文为 2303 → 2579；英文按空白分词为 845 → 850。字符和分词数仅是文本规模指标，不代表模型 token 测量。
- 非视觉专业页各增加一条对应入口，技术栈页补充 Gin 与数据库结构回指；完整资源目录按需读取。视觉方法页减少 211 行，没有增加默认外部调用、订阅或验证关卡。未发现实质执行成本退化，不宣称所有成本绝对不变。

## 独立只读评审

评审使用新上下文，提供用户需求与已确认方案、适用指令、修改前快照、当前文件、完整差异、上游固定版本原文及验证输出。评审者先形成独立结论，再核对上述变更评估。

结论为通过，限于文档接入、路由和静态完整性；没有查实需修正的退化、重要遗漏或阻断问题。独立检查确认两种语言的结构、远程链接、资源迁移、原有能力和条件对应，并追踪以下请求：

| 请求 | 评审确认的行为 |
| --- | --- |
| 只要营销文案参考网站 | 进入获客资源页，返回现成站点与用途，不启动写作或采集 |
| 查已有 MySQL 权限结构 | 进入 DrawSQL 等既有来源，并按需核对实际源码，不自动设计新库 |
| 无 Mobbin MCP 或 21st CLI 时查 React 登录源码 | 使用可直接访问的组件源码来源；单个服务不可用不阻断其他来源，也不要求安装工具 |
| 用真实产品画面制作封面和短视频 | 进入视觉专业指导，保留图片和视频制作能力及实际导出要求 |
| VPS 监控面板先看案例 | 查看现成面板、ID、JSON 和指标依赖，不自动安装或导入 |
| 审查已有需求的验收条件 | 使用需求专业指导，不自动迁移到模板平台或展开完整故事地图流程 |
| 直接将 Awesome Compose 用于生产 | 说明示例的本地开发边界，按生产部署指导判断适配，不据此自动执行部署 |
