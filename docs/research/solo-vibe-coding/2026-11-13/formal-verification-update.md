# 形式化验证接入变更评估

中英文 Solo Vibe Coding 已接入按风险选择的形式化验证指导，并将性质测试作为独立的测试补充。主要操作说明按需加载，复用既有质量检查和项目知识约定。本轮证据覆盖文档接入、静态完整性与只读情景理解，不包含验证器运行或真实工程效果验收。

## 变更与目标

| 目标 | 修改前 | 修改后与依据 |
| --- | --- | --- |
| 选择验证方法 | 有测试、工程纪律和按风险选择检查的指导，没有形式化验证专门入口 | 两语言各新增 formal-verification.md，区分模型检查、代码验证、抽样测试和保证范围 |
| 建立并维护验证 | 一般质量检查要求可复跑且能拦截违规 | 补充业务性质、假设与界限、代码映射、缺陷有效性验证、同步提交及变更后复核 |
| 串联任务 | 需求、架构、开发与质量已有独立入口 | 四类页面增加相关指引，统一进入专项页，保持原有职责 |
| 日常性质测试 | 已有 JS/TS、Playwright、Cypress 和 Go 测试指导 | 增加 Trail of Bits 的性质测试入口，沿用项目库并区分抽样证据与证明 |
| 复用上游 | 尚未接入本次候选 | 接入 Cursor 创建／维护两项与 Trail of Bits PBT；TLA+ 路线注明同版本 statechart 依赖 |

[候选与来源核查](formal-verification-selection.md)保留发现依据；[只读情景输入与实际回复](formal-verification-walkthrough.md)保留本轮观察。正式操作从[中文专项页](../../../../i18n/zh-CN/skills/solo-vibe-coding/references/formal-verification.md)或[英文专项页](../../../../skills/solo-vibe-coding/references/formal-verification.md)读取，不依赖这些档案。

## 能力 约束与成本

正式包共涉及十份文件：每语言修改四份参考页并新增一份专项页；原有段落、来源和文件均保留。修改前技能包内容与 `c6a9c0b31c53a291b9e7ae785078c62a077076c1` 一致。本次实际 diff 没有改变 SKILL.md、agents 元数据、技术栈、部署、Runner、工程纪律、现有检查及知识库约定，没有新增默认安装或工具运行要求。网站及其相关文档的其他并行修改不在本次评估范围。

新增指导明确了原先没有专门表达的验证能力与适用边界，符合当前接入目标。成本包括有限但实际新增的阅读和维护量：英文四份已有参考页合计增加 258 个按空白切分的词，独立专项约 512 词；中文已有四页合计增加 963 个字符，专项 1800 字符。它们是文本规模指标，不是 token、阅读时间或工程执行成本的测量。

专项按当前任务的影响、测试覆盖缺口和成本选择；主入口不增加通用启动关卡。情景走查中，普通文案修改沿用已有检查，没有要求进入形式化验证。未发现实质能力、默认运行步骤或授权边界退化；以上证据不能证明所有实际使用成本不变，也没有证明相对原版本的工程效果提升。
