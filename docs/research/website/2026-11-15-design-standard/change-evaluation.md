# 官网设计规范提炼与差异评估

## 请求与依据

用户在金属深空版和当前玻璃折射版表达认可后，要求“抽取一个复用的规范”。中间钴蓝版曾被否定，说明完整、统一、有主图和工程通过不能充分解释用户审美。本轮只抽取适用于此类风格的操作方法，不将审美偏好升级为 Skill 默认规则，不修改网站、提交或部署。

比较基线为 `54a6059416a6afe58f77002cc9667a38de62b024`。此前工作区两份 SKILL.md 各有八行用户修改，按原样保留。接受与否的反馈来自本次会话，不是用户群体研究；基准画面见[金属版桌面](../2026-11-14-immersive-orbit/screenshots/zh-CN-desktop-hero.png)、[玻璃版桌面](../2026-11-14-prism-nocturne/screenshots/zh-CN-desktop-hero.png)与[玻璃版手机全页](../2026-11-14-prism-nocturne/screenshots/zh-CN-mobile-full.png)。

## 实际差异与评价

| 前后差异 | 对应价值 | 成本与边界 |
| --- | --- | --- |
| 原先只有项目具体规范与历史制作记录；新增独立的电影感材质官网规范 | 首次使用者能直接获取适用范围、构图与选材方法、制作步骤和任务简报，无需自行拼接聊天历史 | 增加一份约四千字的可选文档；其维护成本与代码例子的时效性需要保留 |
| 将稳定体验与可变表达分开，具体颜色和尺寸只作起点 | 复用空间、材质、层级与节奏的判断，而不要求复刻玻璃、光环或固定布局 | 这些是受当前样本启发的设计指导，跨项目能否维持审美仍需实际作品检验 |
| 以审美、产品理解、操作和工程分别验收 | 防止技术通过代替画面判断、真实用户效果或性能研究 | 检查与对照有实际成本；本规范不新增逐阶段用户审批或额外运行依赖 |
| 知识库和官网需求增加短入口；研究索引登记维护记录 | 规范可发现，项目具体要求和历史依据继续分开维护 | 只增加文档导航，不修改官网用户入口、功能、路由、发布配置或 Skill 行为 |

从实际 diff 看，本次新增的是可选择的设计知识，原有运行路径和约束未改。文档链接与保护文件校验支持范围控制；尚未用新项目验证复用价值，不能据此宣称设计质量已能稳定复现或已经证明全部维度的 Pareto 改善。

## 检查证据

- 已读完整新增规范及两处已跟踪导航 diff，排除聊天过程、被放弃方案及发布暂态进入规范。
- 相对文档链接逐一解析；新增规范引用的四个 Astro 文件存在，配色与布局起点可与 Hero.astro 对照；Canvas 动画循环和像素比起点可与 PrismScene.astro 对照。
- 文字对比与暂停条件核对 W3C 官方说明，分别在规范相关位置引用；44×44 CSS px 明确为设计约定，不表述为 WCAG AA 最低标准。
- `git diff --check` 通过，另检查新增文件末尾换行及链接。两份原有 Skill 修改的 SHA-256 与制作前一致：英文 `2c0e6aaff3e9c54c236984161695ff9ba290fa5cf6177e5b2fabf5ed4e64111c`；中文 `9ba09eca6d993e0bb1ea0fd3c94ea867fd98db59628f6f337db0a174e10ea5f4`。
- 本轮只改维护文档，不重新运行网站构建或浏览器测试，不将上一轮网站测试计作本轮规范的效果证据。独立只读审查另存[审查记录](independent-review.md)。
