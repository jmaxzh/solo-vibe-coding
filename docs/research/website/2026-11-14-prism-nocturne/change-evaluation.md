# 玻璃折射候选差异与成本

本候选试图恢复用户在金属光环版中认可的空间、材质、尺度与构图张力，再以玻璃折射形态与青绿/紫光变化。独立审查先看原始要求、真实diff和三版画面，再核对本评价；不以完整、协调或工程通过证明同等级审美已复现。

工程基线为ba342fd（被否定的钴蓝版），视觉比较对象为f2b27f3（认可的金属版）。本分支为website/prism-nocturne，只推送GitHub草稿PR，确认前不合并main、不正式发布。

## 真实差异

| 变化 | 对应目标 | 证据与边界 |
| --- | --- | --- |
| 纸面蓝字/折纸改为全幅烟熏玻璃，白字与局部稳定暗部，青绿主要行动 | 让材质、明暗与文字共同形成空间，保留单一阅读焦点 | 同视口认可版/被否定版/本候选对照；独立审查确认旧分栏弱点解除，但用户审美未确认 |
| 桌面主图贯穿画面；手机与中间宽度按内容流排图，整体场景边缘渐隐 | 守住大尺度与前后层次，同时不压正文或显出图片框 | 修正分栏过于保守、601/801接缝和亮玻璃上口号对比不足；像素/命中/断点复核 |
| 恢复侧栏任务示意与叙事痛点，使用克制的深色/局部紫光贯穿演示、证据和安装 | 让首屏之后维持相容节奏，保留产品理解路径 | 主要排版节奏沿用认可版；不把现有功能、文案或布局复用计作新增产品能力 |
| 新原生Canvas粒子/折射光线及轻量指针视差，统一暂停/减少动画 | 提供与玻璃材质相容的轻动效 | 比较真实Canvas签名及真实图像位移，核对暂停/离屏/恢复/减少动画；没有实时3D模型 |
| 测试从矩形不得重叠改为背景型画面实际对比与入口命中，流式布局仍检查分离 | 验证真正的阅读和操作，而非把背景照片等同于遮挡 | 所有50项原行为保留；4项扩展到14宽度，标题≥3、简介/注记/口号≥4.5，含指针两端；属于采样证据，非完整WCAG认证 |

## 成本

相对工程基线：产物917631→973254 bytes，增加55623 bytes（54.3KiB，6.1%）；JavaScript17198→17256 bytes（+58）。新WebP127248 bytes，旧75190 bytes，增加52058 bytes。没有增加依赖/框架/字体/后端，仍在原5MiB和60KiB预算内。

相对认可版：产物1022768→973254 bytes，减少49514 bytes（48.4KiB，4.8%）；不能选择这个比较来掩盖相对实际基线的资源增长，也不能从字节变化推导外网速度或功耗。

中文1440全页：工程基线7974→7085px（-11.1%），认可版7195→7085px（-1.5%）。390全页：9832→9121px（-7.2%），认可版9117→9121px（+4px）。演示位置桌面1548→1248px、手机1277→1207px；相对认可版约1344→1248和1203→1207。更少滚动不直接作为更好理解或更高转化的证据。

Canvas从独立图像区域扩大至桌面首屏，仍有持续绘制开销；绘制上限30fps、DPR上限1.5，离屏/隐藏/暂停/减少动画停止。没有实体设备性能或功耗研究。

完整源码、截图和制作原图增加仓库档案体积；静态预览ZIP603671 bytes，不进入正式站点构建或运行。档案和原图不作为运行依赖。

## 判断边界

独立审查认为修订后的桌面具备大尺度、前后遮挡、暗部与折射共同构图，可作为有完成度的候选交用户确认。玻璃结点比金属大环更密、正文节奏更安静，用户是否偏好仍未知；不宣称同等级审美、理解、使用效果或总体Pareto改善已得到证明。
