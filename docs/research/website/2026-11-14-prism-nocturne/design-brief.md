# 玻璃折射版制作目标

本轮回应用户要求：“重新总结之后再做一版，发到GitHub上，等我确认”。以用户认可的金属光环版f2b27f3作为视觉比较对象，以当前主分支ba342fd作为工程差异基线。只提交独立分支与草稿PR；确认前不合并main、不发布正式GitHub Pages。

## 复盘后的判断修正

有主图、统一色彩、动效和完整页面，不能推出同等级审美。上一轮优先做出风格差异，却没有充分守住已获认可的空间、材质、尺度关系和构图张力；工程检查也不能代替这项判断。

本轮用“烟熏玻璃与折射光谱”检验新的具体画面，不将这次制作过程写成Skill通用规则，也不宣称方法已经稳定验证。

| 观察维度 | 本轮具体目标 | 比较方式 |
| --- | --- | --- |
| 空间与材质 | 有前后遮挡、内部暗部、可辨厚度与局部折射光；避免平面色块替代材质 | 原图、首屏与金属版同视口并排 |
| 视觉焦点 | 玻璃形态提供吸引力，白字承担阅读，青绿用于主要行动 | 检查标题、图像与按钮之间是否竞争、是否仍能立即辨认定位 |
| 尺度与构图 | 桌面首屏同时呈现定位、主要入口及主视觉关键轮廓；手机保留文字后自然排图 | 1440×1000、390×844及中间断点，含指针移动后的间距 |
| 整页节奏 | 演示、痛点、步骤、证据、安装与FAQ共同延续深色材质与克制光色 | 完整页面对照，分别判断画面与内容理解 |
| 操作边界 | 原助手+Skill关系、四任务与证据性质不变，保留既有功能 | 原行为断言、无JS、键盘、暂停/减少动画及内页对比 |

## 证据与交付边界

工程证据检查功能、布局、资源及构建。独立审查先看原始要求、前后画面与源码，再核对维护者评价；不把“无错误、协调、与之前不同”写成同等设计水平已获确认。

交付完整可操作预览、中英桌面/手机截图、与认可版及被否定版的对照和GitHub草稿PR。最终审美由用户确认；无真实用户理解、转化或实体设备性能研究。
