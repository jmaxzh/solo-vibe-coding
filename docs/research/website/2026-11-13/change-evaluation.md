# 官网初始版本差异评估

基线为 `8d4a0aea8fbcbd4acba79709f93c3b54522ff6be`。本评估在独立评审形成初步判断后编写，依据 `git diff HEAD` 的实际文件差异与验证结果。

## 结论与状态

相对原仓库，新增了隔离的双语官网、发布检查与项目知识库。现有两个 Skill 包没有差异，安装命令、能力边界与其运行依赖未改变。新增官网的构建与维护成本在独立工程中明确承担，没有转移到 Skill 的安装与运行路径。

初次独立评审未发现阻断发布的源码或内容缺陷。本地构建、产物与浏览器验证已通过；首次 Linux CI 与公网部署仍需执行，完成前不将整体验收标为通过。

## 约束与成本核对

- 公开仓库与标准 GitHub Linux runner 的免费计算条件已核对；没有购买域名、运行服务器、外部分析服务或使用大规格 runner。
- 官网引入独立 npm 锁文件、Node 构建环境、双语维护和浏览器检查成本；原有技能包不增加这些依赖。当前静态产物约268.5 KiB，JS约1.7 KiB，低于明确预算。
- 自托管字体增加约几十 KiB 资源，完整 OFL 许可随产物分发；图形源文件与分享 PNG 均保留。
- CI 不启用依赖缓存，Pages 产物保留一天。平台存储费用与计算免费条件分开说明。
- 研究档案只保存追溯材料，不被网站构建引用；档案单独变化不触发无必要的官网发布。
- 原有分发、许可和能力边界未发现退化；不存在为了通过检查而削弱既有测试或降低门槛的修改。
