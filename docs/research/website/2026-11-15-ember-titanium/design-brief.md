# 黑钛熔光版制作目标

用户要求使用已整理的电影感材质官网设计规范，重新制作一版并发布 GitHub Pages，供其检查实际效果。工程与视觉基线均为 `471e3cd`，即已认可的玻璃版加设计规范；使用 `website/ember-titanium` 隔离工作树制作，保护主工作区原有两份 Skill 修改。

本版将材质、形态和光色改为拉丝钛金属、厚边缘与铜色内光，保留可辨纵深、全幅尺度、稳定阅读区和整页连续性。横向四任务选择与宽幅证据行用于延展表达；原有产品事实、文案、四痛点、双语、路由与任务连续性保持。装饰与使用示意、实际执行记录、功能示例继续分开。

完成后按现有流程提交、合并并发布，核对实际公开网址与功能。提供中英桌面和手机首屏、全页及同视口前后对照。工程与审美分别报告，不把发布或测试通过当成用户已认可规范复用效果。
