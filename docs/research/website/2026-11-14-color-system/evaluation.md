# 配色变更自评

结论：本轮将分散的蓝、橙、青柠和暖白替换为全站一致的石墨黑、冷灰分层和薄荷青强调，落实用户希望的技术气质，并保留阅读与操作层级。工程与维护成本没有发现实质退步；是否符合用户个人审美、是否提高转化仍待实际反馈。

| 实际变化 | 服务的目标与证据 | 成本与边界 |
| --- | --- | --- |
| `global.css`建立背景、表面、抬升、悬停、文字、边界、强调、选中、焦点与反馈角色，替代散落颜色；组件使用同组变量 | 所有页面类型的桌面/手机、双语截图显示相同色彩层次，首页与内页共用低饱和深色品牌面 | 色彩角色增加但集中维护；保留原有字体、排版与组件；未引入主题切换、依赖或运行服务 |
| 主标题第二句和主要操作使用薄荷青；正文柔白/浅灰，卡片与阅读面以明度分层 | 主行动与次要链接、标题与描述能通过明度及面积区分；素材保留原色，构成视觉重心 | 属于设计推断，不把个人审美或用户转化认作已验证结果；长文深色阅读偏好尚未试用 |
| 重设表单、代码、复制、选中、错误、禁用、键盘焦点和浏览器配色 | 26种实际状态检查中普通文字最低6.18:1、必要边界/焦点最低4.10:1；选中边框、错误文字和焦点在色觉模拟中仍可辨；38项现有测试通过 | 覆盖选定状态与页面，不等于全站WCAG认证；禁用状态按豁免单独检查；浏览器测试为Chrome/CI Chromium |
| favicon、主题元数据与社交分享图同步；PNG使用级别9无损编码 | 发布分享图由基线53,558降至42,105字节；同一新SVG的默认PNG为55,476字节，级别9编码后为42,105字节，解码像素SHA256完全一致；分享图与网页配色一致 | 未重画或生成素材；第三方图片与设备原样式不变 |
| 官网规范与维护说明同步语义颜色及检查方法 | 首次维护者可直接定位色彩源和需覆盖的状态；研究记录与运行时分离 | 两份Skill用户既有修改原样保留；本轮不更改Skill默认行为 |

整体发布目录由787.4降为777.6 KiB，JS保持13.1 KiB，依赖和所有浏览器脚本不变。27项内容数据、脚本、素材、许可、设备样式、依赖与测试文件逐一比对一致；见`preservation.json`。实际diff还移除了四个场景原有的内联浅色主题，统一使用语义背景，未更换场景内容。

Impeccable静态检查保留一条旧引文2px中性边线警告，未将本轮配色任务扩大为旧案例版式重做；需要独立复核其是否影响目标。暂无真实用户、环境光、各类显示器、跨浏览器色彩感知和转化效果证据。发布核验另行记录，未完成线上同SHA核对前不声称已上线。
