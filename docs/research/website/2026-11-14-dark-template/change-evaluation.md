# 深色分栏首页的差异与成本

本版完成用户要求的“换一套模板”：以开发者官网的左右分栏替换居中浅蓝构图，并重排任务条、区段标题、痛点网格和行动区。产品文案、任务数据、路由与交互脚本保留，工程和原行为验证通过；用户尚未确认这一审美，不能把新构图或缩短页面等同于用户价值、转化或 Pareto 已获验证。

## 实际差异

基线为已发布的 `725ffb4`，工作树为 `website/new-template`。真实比较方法为 `git diff 725ffb4 -- website docs`；独立审查先检查前后代码和截图，再对照本文。

| 差异 | 服务目标 | 已有证据与限制 |
| --- | --- | --- |
| 居中首屏改为左文案/右示意，手机单栏 | 定位、开始方式、实际用法在同一桌面首屏内可见 | 同视口截图显示完整任务流程在1000px高视口内；访客是否更易理解未做用户测试 |
| 深黑背景、青绿强调、分栏区段标题、连体痛点网格、明亮安装区 | 形成与上一版明显不同的开发者官网节奏 | 双语桌面/手机全页与新旧对照；独立审阅认可构图变化，用户偏好尚未确认 |
| 侧栏任务选择改为示意顶部四选项 | 减少示意框架与移动端空间，保留原有选择语义 | 原生单选、正确可访问名、键盘、刷新、语言切换、无脚本与上手延续检查不变 |
| 减少区段间距与重复框架 | 控制完整首页的滚动量 | 中文桌面5790→4898px（-15.4%），390px手机8204→7889px（-3.8%）；文字和功能未删，滚动少不自动证明理解更好 |
| 首页复制按钮至少44×44px，窄屏图注高度自适应 | 满足触控与完整图注阅读要求 | 审查发现后修复；双语320px图注无裁切，40项响应式任务审计包含可见按钮/主行动/任务标签尺寸断言 |
| 首页主题提示与Logo、焦点、复制按钮局部适配 | 首页深色下可读可操作，内页继续稳定 | 首页深色/内页浅色；28项内页正文、链接、计算样式比较相等 |

## 参考与工程范围

[RicoFast](https://ricofast.pages.dev/) / [源仓库](https://github.com/ricocc/ricoui-saas-template) 用作分栏开发者官网的视觉模板参考。其README自称MIT，但当前仓库没有独立LICENSE，故没有复制其源码、字体、图片或图标，也没有导入工程依赖。实现仍由现有Astro组件、CSS和原生脚本组成。来源说明保存在网站视觉来源文件，不让运行时依赖本档案。

Skill、中英文产品数据、原有交互脚本、测试断言、公共global.css、依赖与锁文件、Astro配置、Actions和路由均未改变。官网仍为17页静态站。JavaScript维持13.6 KiB，站点约803.1 KiB，没有新增网络服务。

## 剩余成本与证据缺口

- 大标题从居中64px改为分栏约49px，窗口信息更集中；方法说明、交付标签和主要介绍等关键字号已恢复，触控区已核对。不同屏幕上的舒适程度仍需真实用户判断。
- 首页深色与暖纸内页存在明暗跳转，沿用原品牌、字体、路径和行为降低割裂；内页视觉尚未迁移。
- 主要手机正文为14px，示意正文为13px，辅助说明和图注较小。自动检查与设计审阅不能替代视力差异、实体设备和完整读屏体验。
- 用户只要求换模板，没有确认深色方向；该方向是说明后的默认设计假设。实际审美、理解、首次安装和项目使用效果仍待反馈。

实现检查通过及独立审查无阻断，不构成所有相关价值维度均已无退化的总体结论。最终审查见 [independent-review.md](independent-review.md)，完整检查见 [verification.md](verification.md)。
