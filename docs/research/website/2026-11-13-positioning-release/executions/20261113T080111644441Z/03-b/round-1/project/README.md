# 拾页收藏

一个给自己保存网页的小工具，支持新增、删除、搜索、分类筛选和 CSV 导出。界面采用暖白、墨绿和橙色，适配手机；无需账号、数据库或付费服务。

使用 HTML、CSS 和原生 JavaScript，无构建步骤。运行 `python3 -m http.server 4400 --bind 127.0.0.1`，打开 http://127.0.0.1:4400/ 。页面运行无需安装 npm 依赖。

收藏只存在当前浏览器的 localStorage，键名为 `solo-bookmarks-v1`。查看已有收藏时，请使用原来的浏览器及访问地址（包括端口），因为不同地址的本地存储互不共享。

在“我的收藏”旁点击或轻触“导出收藏”，下载 `拾页收藏.csv`。导出包含全部已保存收藏，不受当前搜索或分类筛选影响，列顺序为标题、网址、分类、备注；没有收藏时按钮禁用。导出不会修改收藏，也不会提交正在填写的表单。

文件使用带 BOM 的 UTF-8 编码，可在 Windows Excel 中直接打开；逗号、双引号和备注换行均会保留。若 Excel 没有显示完整多行备注，开启“自动换行”并调整行高即可查看。手机端根据浏览器提示下载或保存文件。

本地检查需要 Node.js（建议 26 或更新版本）：首次运行 `npm ci`，随后运行 `npm run check`。jsdom 仅用于开发时模拟 DOM。检查涵盖收藏操作、数据保留及导出内容；质量标准见 [CONSTRAINTS.md](CONSTRAINTS.md)。真实手机浏览器下载和 Windows Excel 打开效果需另行验收。
