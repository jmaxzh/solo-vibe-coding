# 质量检查

页面继续使用 HTML、CSS 和原生 JavaScript，无运行时依赖、构建步骤或远程服务。收藏沿用 `solo-bookmarks-v1` 及现有数据结构；导出只读取数据。

修改后、交付前运行 `npm run check`。该命令执行 JavaScript 语法检查及 Node.js 测试；任何语法错误、断言失败或工具错误均须修复后再交付。

- 存储与交互：已有数据加载后不被改写；新增、删除、搜索、分类筛选和重新加载保持可用。
- 导出：全部收藏按标题、网址、分类、备注输出；文件带 UTF-8 BOM，记录以 CRLF 分隔，字段中的逗号、双引号、换行及空白完整保留；不改变收藏或筛选状态。
- 下载：按钮触发 CSV 下载，空收藏时禁用，失败时显示反馈，临时链接与对象 URL 得到清理。

自动化使用 Node.js 内置测试器与 jsdom 模拟 DOM，不启动浏览器。真实浏览器中的手机布局、点击下载及 Windows Excel 打开效果需另外验收。原生页面没有编译流程；不为本项目设置无测量依据的覆盖率、复杂度或性能数字门槛。
