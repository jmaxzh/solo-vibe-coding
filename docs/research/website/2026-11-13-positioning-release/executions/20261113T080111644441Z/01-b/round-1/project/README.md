# 拾页收藏

一个给自己保存网页的小工具，支持新增、删除、搜索、分类筛选和 CSV 导出。数据只存在当前浏览器 localStorage，键名是 `solo-bookmarks-v1`。

使用 HTML、CSS、原生 JavaScript，无构建依赖。运行 `python3 -m http.server 4400 --bind 127.0.0.1`，打开 http://127.0.0.1:4400/ 。

页面采用暖白、墨绿和橙色，支持手机布局。收藏与导出均在本地完成，无需账号、数据库或付费服务。

## 导出收藏

在原浏览器、原访问地址打开页面，已有收藏会继续保留。点击“我的收藏”旁的“导出收藏”，下载 `拾页收藏-YYYY-MM-DD.csv`。手机上也可点击同一按钮，在浏览器的下载列表中找到文件。

导出包含全部收藏，按当前保存顺序排列，不受搜索或分类筛选影响；列依次为标题、网址、分类、备注。没有收藏时，按钮禁用，添加一条后即可导出。导出只读取数据，不会删除或修改收藏。

文件采用带 BOM 的 UTF-8 编码和标准 CSV 转义，可在 Windows Excel 中直接打开，中文、备注中的逗号、双引号与换行都会保留。若单元格没有显示多行，可在 Excel 中开启“自动换行”查看。

## 本地检查

使用 Node.js 18 或以上运行 `node --test`，无需安装 npm 依赖。检查范围与验收要求见 [CONSTRAINTS.md](CONSTRAINTS.md)。
