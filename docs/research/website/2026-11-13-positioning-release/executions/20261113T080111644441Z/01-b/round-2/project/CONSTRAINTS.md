# 质量与验证

本项目保持 HTML、CSS、原生 JavaScript 和 `solo-bookmarks-v1` 本地存储，无构建或运行时依赖。

修改后运行 `node --test`（Node.js 18 或以上）。所有测试须通过；语法错误、断言失败或测试工具错误均阻止交付。

自动检查覆盖以下行为：

- 读取已有数据时不改写存储；新增、删除、搜索、分类筛选和重新加载保持可用。
- CSV 按标题、网址、分类、备注导出当前搜索与分类筛选后的收藏，顺序与列表一致；清空搜索并选择全部分类后导出全部。带 UTF-8 BOM，使用 CRLF 分隔记录，并正确保留字段内的逗号、双引号和换行。
- 导出不修改收藏；没有收藏或没有匹配内容时禁用导出并明确提示，不触发下载。下载使用当前数据并释放临时资源。

测试使用 Node 模拟 DOM 和下载接口。手机布局、键盘与触控、浏览器实际下载和 Windows Excel 直接打开须在对应环境中验收。页面保持现有配色、响应式布局和可见焦点，导出按钮支持键盘并提供至少 44px 的触控高度。

本项目无编译步骤，自动检查以数据兼容、导出格式和交互结果为验收依据。涉及这些行为的修改须补充相应断言；样式改动检查手机窄屏与桌面布局。
