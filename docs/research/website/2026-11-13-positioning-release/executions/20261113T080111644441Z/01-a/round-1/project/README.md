# 拾页收藏

一个给自己保存网页的小工具，支持新增、删除、搜索、分类筛选和 CSV 导出。数据只存在当前浏览器的 localStorage，键名是 `solo-bookmarks-v1`。

使用 HTML、CSS 和原生 JavaScript，无构建依赖。运行 `python3 -m http.server 4400 --bind 127.0.0.1`，打开 http://127.0.0.1:4400/ 。继续使用原有浏览器和访问地址，即可读取该地址下已保存的收藏。

采用暖白、墨绿和橙色样式，支持手机操作。使用本地存储，不需要账号、数据库、远程服务或公开发布。

## 导出收藏

点击或在手机上轻触「我的收藏」旁的「导出收藏」，即可下载 `拾页收藏-YYYY-MM-DD.csv`。如果手机浏览器询问保存位置，按提示保存文件；下载记录中也能找到文件。

导出包含当前浏览器里的全部收藏，不受搜索或分类筛选影响，按现有收藏顺序排列。文件依次包含「标题、网址、分类、备注」四列，使用带 BOM 的 UTF-8 编码，可在 Windows Excel 中直接打开。CSV 字段中的逗号、双引号和换行会完整保留。没有收藏时会提示先添加收藏。

导出不会修改或删除收藏，原有新增、删除、搜索、分类筛选和已保存数据继续使用。所有操作都在本地完成，无需账号或付费服务。

## 验证

运行 `node --test` 检查 CSV 编码与特殊字符、下载触发、完整导出及原有收藏操作。
