# 拾页收藏

一个给自己保存网页的小工具，支持新增、删除、搜索、分类筛选和 CSV 导出。数据只存在当前浏览器的 localStorage 中，键名为 `solo-bookmarks-v1`。

点击「我的收藏」右侧的「导出收藏」，下载 `收藏-YYYY-MM-DD.csv`。手机上也可直接点按，按浏览器提示下载或保存。导出仅包含当前搜索与分类筛选后显示的收藏，顺序与列表一致。搜索仍按标题或备注匹配，可与分类筛选同时使用；没有匹配内容时会提示并禁用导出，不生成下载文件。清空搜索并将分类选为「全部分类」，即可导出全部收藏。

CSV 列依次为标题、网址、分类、备注，使用带 BOM 的 UTF-8 编码，可在 Windows Excel 中直接打开。字段中的逗号、双引号和换行会保留。导出不会更改浏览器中已保存的数据。

使用 HTML、CSS、原生 JavaScript，无构建依赖。运行 `python3 -m http.server 4400 --bind 127.0.0.1`，打开 http://127.0.0.1:4400/ 。已有收藏保存在原浏览器和站点地址下，继续使用同一地址访问即可读取。

界面采用暖白、墨绿和橙色，适配手机屏幕。无需账号、数据库或付费服务。

验证：运行 `node --test tests/export.test.cjs`。
