# 质量约定

页面继续使用原生 HTML、CSS、JavaScript，无需构建；测试工具只作为开发依赖。

提交修改前运行 `npm ci` 和 `npm run check`。检查入口见 [package.json](package.json)，任一语法错误、测试失败或检查执行错误均阻止交付。安装依赖后，日常重复检查只需 `npm run check`。

- 自动验证新增、删除、搜索、分类筛选及已有 `solo-bookmarks-v1` 数据读取；导出不得写回存储。
- 自动验证实际生成的 CSV 字节：UTF-8 BOM、四列中文表头、CRLF 记录分隔、逗号和引号转义、单元格内换行、空备注及 Unicode 内容。
- 自动验证导出与当前搜索和分类筛选的可见列表及顺序一致；无匹配时清楚提示且不下载，清除筛选后可导出全部。覆盖筛选期间新增、删除和重复导出。
- 自动验证空收藏状态、下载文件名和媒体类型，以及下载失败反馈与临时资源释放。
- 测试使用 Node.js 和 DOM 模拟环境；浏览器验收另行确认真实下载、Windows Excel 直接打开、键盘操作及手机宽度下的按钮布局和触控。DOM 测试不能代替这些验收。

沿用暖白、墨绿与橙色样式；导出按钮使用原生按钮、可见键盘焦点和至少 44px 高度，窄屏允许标题与操作区域换行。

不改变存储键及收藏字段，不增加应用运行依赖、远程服务或数据迁移。项目没有编译步骤，不设无依据的覆盖率、复杂度或性能数字门槛。
