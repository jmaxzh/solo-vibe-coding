# 拾页收藏

一个给自己保存网页的小工具，支持新增、删除、搜索、分类筛选和 CSV 导出。数据只存在当前浏览器 localStorage，键名是 `solo-bookmarks-v1`。

使用HTML、CSS、原生JavaScript，无构建依赖。运行 `python3 -m http.server 4400 --bind 127.0.0.1`，打开 http://127.0.0.1:4400/ 。Node.js和npm也可用于当前任务需要的工具。

保持暖白、墨绿和橙色的现有样式，手机也要用。继续使用本地存储，不需要账号、数据库、远程服务或公开发布。变更前已有浏览器数据应保留。

## 导出收藏

在“我的收藏”标题旁点击“导出收藏”，下载 `拾页收藏.csv`。手机上同样点击该按钮，按浏览器提示保存文件。

- 导出全部收藏，包括当前搜索或分类筛选未显示的条目，顺序与未筛选列表一致。
- CSV 包含标题、网址、分类、备注四列，使用 UTF-8 BOM，方便在 Windows Excel 中直接双击打开并识别中文。
- 备注中的逗号、双引号和换行保留在同一个单元格中；在 Excel 开启“自动换行”或调整行高可查看多行备注。
- 导出只生成下载文件，不修改浏览器中的收藏。无收藏时按钮禁用，添加后即可导出。

更新后请继续使用原来的浏览器及访问地址（包括端口），以读取原有收藏；localStorage 按网站来源隔离。

## 本地检查

页面本身不需要安装依赖或构建。检查需要 Node.js（支持范围见 `package-lock.json` 中 jsdom 的 `engines`），本项目可使用 Node.js 26。

```sh
npm ci
npm run check
```

检查使用 Node.js 自带测试框架和 jsdom 验证 CSV 字节、下载触发、数据保留及原有操作。jsdom 仅是开发依赖，不启动浏览器。质量约定及浏览器验收范围见 [CONSTRAINTS.md](CONSTRAINTS.md)。
