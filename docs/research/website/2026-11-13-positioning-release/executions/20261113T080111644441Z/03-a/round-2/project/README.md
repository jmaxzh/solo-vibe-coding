# 拾页收藏

一个给自己保存网页的小工具。支持新增、删除、搜索、分类筛选和导出收藏，数据只存在当前浏览器localStorage，键名是 `solo-bookmarks-v1`。

使用 HTML、CSS、原生 JavaScript，无构建依赖。运行 `python3 -m http.server 4400 --bind 127.0.0.1`，打开 http://127.0.0.1:4400/ 。

界面采用暖白、墨绿和橙色，支持手机布局。收藏使用浏览器本地存储，无需账号、数据库或远程服务。

## 导出收藏

在电脑或手机上，输入搜索词、选择分类后，点击“我的收藏”旁的“导出收藏”，即可下载 `拾页收藏-YYYY-MM-DD.csv`。文件只包含当前列表中同时符合搜索和分类条件的收藏，顺序与列表一致；搜索继续匹配标题或备注，忽略大小写和首尾空格。

清空搜索框并将分类选回“全部分类”，再点击“导出收藏”，即可导出全部收藏。当前没有匹配结果或尚未保存任何收藏时，点击按钮会提示“没有匹配的收藏可导出。”，不下载文件。

CSV 包含标题、网址、分类和备注四列，采用带 BOM 的 UTF-8 编码，可在 Windows Excel 中直接打开。逗号、双引号和备注中的换行会保留；在 Excel 中查看多行备注时，可开启“自动换行”并调整行高。手机浏览器如显示文件预览，可用系统的保存或分享操作保存文件。

导出不会修改浏览器里已有的数据。继续使用原来的浏览器和访问地址，即可保留现有收藏。

## 检查

使用 Node.js 运行 `node --check app.js` 和 `node --test`，检查脚本语法、CSV 编码与转义、导出范围、数据保留以及新增和删除操作。
