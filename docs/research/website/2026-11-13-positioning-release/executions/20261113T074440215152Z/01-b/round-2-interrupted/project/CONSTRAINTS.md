# 质量与验证

页面保持 HTML、CSS 和原生 JavaScript，无运行依赖或构建步骤。数据继续使用当前浏览器的 `solo-bookmarks-v1` localStorage，不因读取或导出而改写。沿用暖白、墨绿和橙色样式。

修改 JavaScript 后运行 `node --check app.js`；交付前运行 `npm run check`。语法错误、测试失败和工具启动失败均阻止交付。测试使用独立浏览器上下文，不操作日常浏览器中的收藏。

自动检查在 jsdom 中运行实际页面脚本，覆盖新增、删除、搜索、分类筛选、重新加载保存数据及已有数据读取；读取实际 Blob 的字节，检查导出与当前列表的内容及顺序一致、无匹配时提示且不下载、清除筛选后导出全部，以及四列表头、UTF-8 BOM、CRLF 记录分隔、特殊字符和空数据。导出不得写入本地存储或修改筛选条件。

断言见 [tests/app.test.cjs](tests/app.test.cjs)。触屏按钮至少高 44px，标题操作区可换行。浏览器人工验收时，在桌面和 320px 窄屏检查无横向溢出、触屏下载和键盘操作，并在 Windows Excel 中打开 CSV 核对四列和多行备注；DOM 测试不代替这些真实环境检查。

使用本地自动检查，不依赖远程 CI。当前规模通过行为测试和源码审查检查复杂度、重复逻辑与边界，不另设覆盖率、复杂度或变异分数门槛；无编译或打包步骤。
