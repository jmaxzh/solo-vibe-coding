# 拾页收藏

一个给自己保存网页的小工具。已有新增、删除、搜索、分类筛选，数据只存在当前浏览器localStorage，键名是 `solo-bookmarks-v1`。

在“搜索收藏”中输入标题或备注关键词，或在“筛选分类”中选择分类，点击“导出收藏”即可下载当前列表中的收藏。搜索与分类同时生效，文件中的顺序与列表一致。没有匹配内容时会显示提示并禁用导出，不会下载其他收藏。

需要导出全部时，清空搜索框并将分类切回“全部分类”，再点击“导出收藏”。文件名为 `拾页收藏.csv`，包含标题、网址、分类、备注四列，保留中文、引号及多行备注。导出不会修改已保存的收藏，也不会清除当前筛选条件。

使用HTML、CSS、原生JavaScript，无构建依赖。运行 `python3 -m http.server 4400 --bind 127.0.0.1`，打开 http://127.0.0.1:4400/ 。Node.js和npm也可用于当前任务需要的工具。

保持暖白、墨绿和橙色的现有样式，手机也要用。继续使用本地存储，不需要账号、数据库、远程服务或公开发布。变更前已有浏览器数据应保留。

开发验证：安装开发依赖 `npm ci` 后运行 `npm run check`，检查标准见 [CONSTRAINTS.md](CONSTRAINTS.md)。日常使用无需安装依赖。
