# 拾页收藏

一个给自己保存网页的小工具，支持新增、删除、搜索、分类筛选和 CSV 导出，适合电脑和手机使用。

使用 HTML、CSS 和原生 JavaScript，无构建依赖、账号或远程服务。收藏只保存在当前浏览器的 localStorage 中，键名为 `solo-bookmarks-v1`。

本地运行：在项目目录执行 `python3 -m http.server 4400 --bind 127.0.0.1`，然后打开 http://127.0.0.1:4400/ 。

## 导出收藏

在电脑或手机上，点击「我的收藏」旁的「导出收藏」，下载 `收藏-YYYY-MM-DD.csv`。手机浏览器若显示预览或保存提示，选择下载或保存到文件。

文件包含全部收藏，按当前收藏顺序排列，不受搜索或分类筛选影响；列依次为标题、网址、分类、备注。没有收藏时，导出按钮不可用。

CSV 使用带 BOM 的 UTF-8 编码和 CRLF 行结束符，可在 Windows 上用 Excel 直接打开。字段用双引号包围，字段内的双引号转义为两个双引号，保留中文、逗号、引号和多行备注。若备注未完整显示，可在 Excel 中开启「自动换行」。

导出不会修改或删除浏览器中的收藏，原有新增、删除、搜索和筛选操作不变。
