# 原始请求

把本项目的官网按以下要求：

你是一位具备艺术指导能力的数字产品设计师与前端工程师。请根据以下项目信息，独立设计并实现一个具有强烈视觉表现力、清楚产品定位和完整操作路径的品牌官网。

项目信息中的产品及用途、目标用户、核心价值与主要行动、已确认内容与功能、技术预算及发布范围均为待填项。复用项目已有信息，自主解决设计选择；仅对影响事实准确性或实现可行性的关键缺口提问。

整个任务仅依据项目输入和以下要求完成，不依赖参考网站、模板、参考图或历史作品。

## 明确要达到的品质

页面同时满足：视觉有力量，有明确主角和鲜明整体印象；近看有造型、材质、排版和细节完成度；产品用途、价值与主要行动容易辨认；完整页面、手机和交互状态都经过设计；实现可运行，主要路径真实可用。清楚、完整、统一和工程正确属于基础要求；视觉表现力独立判断，不能由其他维度代替。

## 从产品推导视觉方向

确定产品适合传达的感受，并转化为形态、材质、光色、字体与构图。在内部探索两至三个构图有明显差异的方向，用简要草图或实际试排比较后选择深化。各方向明确视觉主体与轮廓结构、文字背景整体关系、尺度明暗疏密前后关系、产品适配原因与最可能普通之处。自主选择，依据包含实际画面表现力、产品适配性与实现成本。

## 设计具有表现力的首屏

首屏作为完整场景组织。通过尺度反差、裁切、留白、遮挡和明暗建立主角与张力。文字、主体、背景在比例、轮廓与光色上呼应。版式由内容与构图决定，即使分栏也建立整体关系。主视觉有自身造型与细节，承担品牌印象；产品关系通过形态、隐喻、材质或场景表达。流程和功能放在适合阅读的章节。标题与紧邻说明共同表达产品对象、独特价值与用途，主要按钮指向明确下一步。

## 把素材做到实际需要的精度

根据目标选择原创生成、摄影、离线渲染、图形设计或代码绘制，明确收益成本。材质空间包括清楚结构、轮廓、厚度、前后关系；表面细节受光反射阴影一致；高光暗部色彩有主次；在实际显示尺寸下细节成立；边缘裁切背景衔接自然。风格化表达保持造型受光逻辑。完成度由最终画面判断，不由技术决定。标题正文按钮是真实网页文字；装饰图、使用示意、真实截图、功能成果分别表达。素材核对使用权，保留必要归属。

## 把艺术指导延续到完整页面

按理解与决策顺序组织内容，各章节职责明确。章节尺度、图文比例、留白、背景与布局形成节奏；字体色彩材质暗示线条控件贯穿。真实内容、演示、证据、开始入口、页脚都有完成度。真实文案试排，检查重要空状态、错误状态和展开内容。产品事实案例评价效果数字有依据，视觉增强印象同时保留准确具体说明。

## 完成可靠实现

尊重现有架构功能内容与工作区修改。全新项目轻量方案；新增依赖说明收益与维护成本。手机按阅读操作顺序重构，并检查中间宽度、长内容、自然换行、触控目标、横向溢出。检查实际背景上所有文字对比，包括辅助说明按钮链接与动态背景最亮处。主要内容默认可见；动效补充空间或解释状态，支持键盘、减少动态、必要暂停，控制资源持续绘制成本。主要按钮交互有真实结果，外部服务边界如实说明。

## 按实际画面自检与返工

先静态首屏，再整页手机必要动效。缩小查看完整首屏与整页，检查焦点比例明暗节奏。实际尺寸检查造型材质字体换行间距边缘状态。隐藏文案看主视觉是否独立成立，隐藏装饰看信息操作是否清楚，恢复后看是否增强。指出最有力量决策与最影响品质薄弱处；主视觉仅解释、造型粗略或缺少整体关系时继续深化。优先修复整体构图尺度焦点层级，再局部。工具支持时用新上下文独立只读审查，提供原目标、实际画面和实现证据，先独立判断再看自评，分别评视觉信息操作工程并修复确认问题。

## 完成交付

提供可直接打开操作预览；桌面手机首屏与整页截图；简短主导概念与构图说明；审美、产品理解、操作、工程分别验收；检查结果、实现成本与未验证范围。按指定范围提交发布；未指定发布目标时交付可操作预览。工程检查不替代审美判断。真实用户理解、转化或使用效果需要实际研究。
