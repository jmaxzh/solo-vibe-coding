# 产品表达与文案

适用于已有成熟想法的定位表达、官网与落地页文案、卖点、品牌语气和编辑。产品方向由用户确定；澄清表达所需信息不等于重新做创业选题。用户尚无客户时，将目标人群、需求和效果标明为设定或假设，不编造证明。

## 选择

| 当前任务 | 主选 | 选择依据 |
| --- | --- | --- |
| 整理产品是谁用、解决什么、差异和语气 | product-marketing | 为当前表达建立共同依据，按现有信息补缺即可 |
| 写或重写官网、落地页、功能介绍 | copywriting | 从已定价值写成清楚的页面文案 |
| 有现成文案，要求改得更清楚、自然、具体 | copy-editing | 优先保留真实内容与个人语气 |
| 分析措辞背后的行为心理 | marketing-psychology | 作为具体表达的辅助，不默认增加操纵性手法 |
| 用户要求选传播方法 | marketing-ideas | 从少量相关方法中推荐，贴合时间、资源和受众 |
| 用户要求改善交易内容、权益或交付承诺 | offers | 关注所售内容本身；不是发现新产品方向 |
