# 官网需求与设计规范

官网帮助已有明确产品方向的独立开发者理解 Solo Vibe Coding、尝试一次具体任务，并跟踪项目公开进展。站点使用 GitHub Pages 默认地址，提供对应的英文与中文内容。

## 内容与转化

首要行动是进入安装和首次使用。GitHub 源码、任务指南与构建日志提供深入了解的路径。

| 页面 | 内容与行为 |
| --- | --- |
| 首页 | 项目定位；六类任务示例；独立任务、质量基线、知识积累三个特点；工作方式；安装；构建日志入口；常见问题 |
| 快速开始 | Agent Skills 兼容性、文件与远程文本访问条件、Node.js 22.20+ 与 npm、项目本地安装、全局安装选项、首次调用、人工安装和工具边界 |
| 任务指南 | 六类任务均提供调用示例、相关指导、预期交付和上游入口；补充技术、质量与知识规范链接 |
| 构建日志 | 按实际日期列出已登记文章，文章有作者、独立网址与对应语言版本 |
| 404 | 说明地址问题，并提供可用的首页返回入口；不参与索引 |

能力事实以技能入口、参考文档和仓库 README 为依据。示例描述调用方式与预期交付；只有实际执行并验证的结果才作为案例证据。项目原创内容的 MIT 许可与上游资源各自条款分开说明。

首篇日志介绍建站动机、范围、选择与后续观察，不预先声称已获得用户增长、效率提升、搜索排名或 AI 推荐。

## 语言与网址

英文为默认语言，中文内容位于 `/zh-CN/`。所有页面都位于 `/solo-vibe-coding/` 下，使用目录式网址与尾斜杠。两种语言的页面保持能力、边界、链接用途与结构对应，文案允许自然表达。

语言切换保留当前主题。每页提供自身 canonical 与双向语言替代链接；默认替代语言为英文。英文和中文构建日志共用文章 slug。

## 视觉表达

采用独立开发者工作台与技术出版物结合的方向。暖白、石墨黑与橙色建立主体识别，深色工作台承载调用示例，浅绿色区块突出安装。

当前设计 token 的可执行定义位于 `website/src/styles/global.css`：背景 `#f7f5ef`，正文 `#202320`，强调 `#e4613e`；橙色按钮采用深色文字保证对比度。正文链接使用更深的强调色。

英文使用自托管 Manrope，代码使用 IBM Plex Mono，中文使用系统字体。图标、连接线、笔记本插图与分享卡片源文件采用代码和 SVG；可编辑源随仓库保留。

桌面采用左右首屏、分组说明、步骤与阅读栏的不同布局。手机采用单列首屏、可直接使用的完整导航、可换行命令与适合阅读的正文。动效只承担交互反馈，并响应减少动态效果设置。

## 交互与无障碍

- 首页任务入口初始为普通链接，六个示例均在 HTML 中。启用 JavaScript 后增强为可用左右方向键、Home、End 切换的标签页，并维护选择状态与焦点；直接访问任务锚点时显示对应任务。
- 复制按钮在剪贴板能力可用时出现。复制成功后有文字及读屏提示；失败时选中原文并提示手动复制。
- 安装、指南、语言切换、构建日志与 FAQ 可在关闭 JavaScript 时使用。
- 页面使用语义标题、main 与导航区域，提供跳到正文、清晰键盘焦点和对应语言属性。装饰图形不干扰读屏。

## SEO 与 GEO

核心正文静态生成；每页有独立标题、摘要、canonical、语言链接、分享卡片与合适的结构化数据。sitemap 只列实际内容页面。项目目录不能通过子目录 `robots.txt` 控制域名级爬虫规则；发布时检查域名根目录的实际规则。

结构化数据描述网站、页面、作者、文章与开源创作，不将 Skill 包装成独立在线 SaaS，也不生成未验证的评分。GEO 依靠清晰定义、可读正文、具体示例、来源、作者与实际日期；AI 引用和排名属于上线观察结果。

首版不加载浏览器分析 SDK。搜索表现通过搜索平台站长工具观察；安装命令复制与实际安装量具有不同含义。接入额外数据服务时，应另行确定必要事件、服务条件与数据用途。

## 验收

双语页面、链接、锚点、元数据与语言对应完整；构建和浏览器检查通过；桌面、手机和关闭 JavaScript 后的核心内容可用。发布成功以 GitHub Actions 完成及公开页面实际 HTTP 响应为依据。
