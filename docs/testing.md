# 官网测试与验证

官网验证确切页面范围、双语内容、安装与任务路径、复制、响应式及动画行为。质量门槛见 [CONSTRAINTS.md](../CONSTRAINTS.md)。

## 本地检查

在 `website/` 执行：

```sh
npm ci
npm run validate
npx playwright install chromium
npm run test:e2e
```

`validate` 依次进行 Astro/TypeScript 检查、生产构建和产物验证。Playwright 配置自动启动产物预览；本机使用已安装 Chrome 时，可设置 `PLAYWRIGHT_CHANNEL=chrome`，验证记录应说明浏览器。

## 覆盖范围

| 风险 | 检查方法 |
| --- | --- |
| 遗留或缺失页面 | 精确核对中英文首页、开始使用、任务指南和共用 404；检查旧页面及专属资源返回 404 |
| 路由、资源和锚点失效 | 解析所有产物内链、资源及页面 ID，按项目路径定位实际文件 |
| 语言切换丢失主题 | 元数据双向对应和各类页面的实际语言切换 |
| SEO 遗漏 | 独立标题、摘要、canonical、分享图片、JSON-LD，sitemap 覆盖有效页面并排除 404 |
| 安装入口或复制失效 | 首页进入交付方法与安装，复制完整安装命令，拒绝剪贴板权限后可手动复制 |
| 独立任务丢失范围 | 六类目录、十二个请求、交付边界与检查点；指南进入上手页、复制、安装往返、语言切换和刷新保持同一任务 |
| 更新与版本核对不可用 | 从首页 FAQ 进入折叠更新说明、复制定向命令、进入并复制只读版本核对请求 |
| 无脚本路径不可用 | 在禁用 JavaScript 的上下文阅读指南、安装、全部请求与 FAQ，使用普通锚点进入更新和版本核对 |
| 动效妨碍操作 | Canvas 随动、暂停、离屏停止和恢复、减少动画静态图，601–800px 暂停控件点击命中 |
| 手机溢出或无障碍问题 | 桌面和手机核对全部页面的文档宽度，并运行 axe 严重与关键问题检查 |
| 维护内容误入官网 | 检查本仓库 docs 和工作流链接，保留普通 GitHub 与许可入口 |
| 体积增长 | HTML、JavaScript 和整个发布目录预算 |

新增页面时同步维护路由、双语元数据和产物验证器的确切清单。外链、来源许可与素材公开分发条件需另行核对，静态验证不会请求全部外链。

## 检查工具的有效性

修改产物验证器后，在可恢复的构建目录中注入已知错误，确认命令非零退出；恢复后再验证正常结果。页面清单检查应能拒绝额外遗留页面。

## 用户与视觉验收

使用真实浏览器模拟从能力入口选择任务、安装、复制请求、切换语言和继续阅读的完整路径。观察桌面、手机和中间宽度的排版、焦点、触控与动画偏好，保留必要截图。

工程检查不替代目标用户理解、首次使用成功率、提效或审美判断。安装和版本说明的阅读检查不等于在所有宿主中实测安装更新；未执行的范围应如实报告。

## 生产检查

发布后核对同一提交的 GitHub Actions 检查与部署、双语页面、资源和 sitemap 响应。移除页面与下载资源应返回 404。部署和回退操作见[官网 README](../website/README.md)。

搜索引擎收录、AI 引用、真实用户性能和实际安装量需要上线证据。
